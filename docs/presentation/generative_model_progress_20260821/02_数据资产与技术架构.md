## 2. canonical 与 annotation 分层

```text
final_dataset.csv (唯一索引，2,532)
├── cof_graphs.npz
│   ├── atomic numbers / atom types
│   ├── formal charges / radical electrons
│   ├── centered XYZ coordinates
│   ├── sparse undirected true bonds
│   └── atom_offsets / bond_offsets
├── symmetry_data.npz
│   ├── target_pg / actual_pg / exact / compatible
│   ├── operation matrices R_g
│   ├── atom permutation indices P_g
│   ├── orbit_id / orbit_size
│   └── operation RMS / mean / max symmetry error
├── rdkit_features.npz
└── manifest + fixed splits + hashes
```

模型 adapter 可以移除 H 或构造 full-pair 表示，但不能修改 canonical ground truth，不能把
Sn 映射成 C/Si，也不能把 charge/radical 静默置零。

## 3. 已完成的评测闭环

- 化学：RDKit sanitize、连通性、原子/键 exact、价态和芳香性。
- 几何：coordinate RMSD、pair-distance MAE、碰撞、质心归零。
- 生成：validity、connected、collision、uniqueness、novelty、训练集最近邻相似度。
- 对称：actual point group、target exact、target compatible、operation/orbit symmetry error。
- 数据划分：IID 与 Core-OOD；test/Core-OOD 不参与调参和 checkpoint 选择。

## 4. 推荐目标架构

```text
                         external 2D graphs
                       /                    \
Target_PG ──> topology/template generator ──> valid heavy-atom graph/SMILES
     │                    │                              │
     │                    └── graph automorphism/orbits ┤
     │                                                   v
     └────────────────────────────────────> graph-conditioned 3D model
                                                         │
                                  target operations/orbits│
                                                         v
                                   hard/soft symmetry projection
                                                         │
                                            add H + constrained relax
                                                         │
                                                         v
                             sanitize + collision + actual-PG validation
```

关键变化是：第二阶段已知化学图，因此 3D 模型只需要生成坐标/构象，不再同时解决极度稀疏的
N² 键存在性分类。这直接绕开当前 UAE/MiDi 的主要失败点。

## 5. 建议分阶段目标

### Stage A：已知 graph → 指定 PG 的 3D

先使用数据集中真实 SMILES/graph，训练 graph + Target_PG → coordinates。该阶段不承担新
化学图生成，能直接检验 symmetry condition 和 3D decoder。

### Stage B：Target_PG → 新 graph/SMILES

使用 template/grammar baseline 和条件 2D graph generator 并行。输出只代表 topology
symmetry propensity，必须经过 Stage A 和 3D analyzer 才能宣称满足点群。

### Stage C：端到端候选生成

将两个阶段串联，使用 actual PG、symmetry error 和化学质量作 reranking；成熟后再研究
联合训练或 latent coupling。
