# 外部数据与待执行命令

本文只保存候选数据及命令，**本轮没有执行任何下载或解压**。正式下载前应先确认磁盘、许可、
目标模型和数据 schema，下载后立即记录 checksum。

## 1. 数据优先级

| 数据集 | 规模 | 适合用途 | 与 COF 的主要差异 | 优先级 |
|---|---:|---|---|---:|
| GEOM-Drugs | 约 31.7 万 drug-like species；GEOM 总计约 45 万分子/3,700 万构象 | graph-conditioned 3D、UAE/UDM 官方数据路线 | 无 PG 标签；元素/尺寸需重新审计 | 1 |
| QMugs | 约 66.5 万分子、约 200 万构象；structures 压缩包约 7 GB | 大分子 3D 预训练、域多样性 | 无 PG 标签；量化方法与 COF 不同 | 2 |
| QM9 | 约 13 万、单个低能构象、最多 9 个重原子 | 工程 smoke、小分子预训练 | 尺寸和元素域偏离最大 | 3 |
| GuacaMol/MOSES | 百万级 2D drug-like graph/SMILES | 2D graph/SMILES generator 预训练 | 没有 3D 和 PG | 2D 专用 |

推荐先选择一个 3D 数据源，不同时下载全部数据。对于当前路线，GEOM-Drugs 与 UAE、GeoDiff、
Torsional Diffusion 的官方生态最接近。

## 6. 下载后必须先做的审计

在任何联合训练前生成独立报告：

1. 原始文件 SHA-256、来源 URL、下载日期和许可。
2. RDKit 可解析/可 sanitize 数量。
3. 元素、charge、radical、原子数、键型和构象数分布。
4. 与 13 元素 vocabulary 的交集/差集；Si/Sn 不允许 fallback。
5. graph/coordinate 一致性和单位。
6. 与 COF train/val/test 的 SMILES/Morgan 重叠，防止外部预训练泄漏测试结构。
7. 使用与 v2 相同的 point-group analyzer 重算实际点群；外部样本不得继承伪造 target_pg。

## 7. 联合训练采样建议

- external pretrain：只学习通用 graph 或 graph→3D，不使用 PG condition。
- COF adaptation：每 batch 显式控制 external/COF 比例，例如从 `3:1` 起做预冻结对照。
- PG fine-tune：只使用 COF IID-train；C2/C3 分层采样，S4/D6h 以探索性 episode 加入。
- val：固定 COF IID-validation；test/Core-OOD 在所有模型选择完成前保持封存。
