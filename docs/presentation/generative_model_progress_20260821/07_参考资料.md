## 2D graph generation

- DiGress：
  [paper](https://openreview.net/forum?id=UaAD-Nu86WX)；
  [official code](https://github.com/cvignac/DiGress)
- SparseDiff：
  [Sparse Training of Discrete Diffusion Models for Graph Generation](https://openreview.net/forum?id=oTRekADULK)

DiGress 支持 graph-level conditional generation，但官方仓库也注明部分旧 checkpoint 已不可用，
因此应优先审计代码/数据接口，不假设预训练权重一定可下载。

## graph-conditioned 3D conformer generation

- GeoDiff：
  [paper](https://openreview.net/forum?id=PzcvxEMzvQC)；
  [official code](https://github.com/MinkaiXu/GeoDiff)
- Torsional Diffusion：
  [paper](https://openreview.net/forum?id=w6fj2r62r_H)；
  [official code](https://github.com/gcorso/torsional-diffusion)
- RDKit ETKDG：
  [RDKit Book — Conformer Generation](https://www.rdkit.org/docs/RDKit_Book.html#conformer-generation)

GeoDiff 和 Torsional Diffusion 都以已知 molecular graph/SMILES 为条件生成构象，适合将
化学图有效性与 3D 坐标生成拆开。

## SMILES 的语义边界

- [Daylight SMILES](https://www.daylight.com/smiles/)
- [Daylight Theory Manual](https://www.daylight.com/dayhtml/doc/theory/)

SMILES 以 atoms/bonds 构成的 graph/connection table 为核心，可编码部分局部立体信息；它
不是唯一的 3D equilibrium geometry。因此本项目必须在生成坐标后重新判定 actual point
group，不能把条件 SMILES 的标签直接当作最终 3D 对称性。
