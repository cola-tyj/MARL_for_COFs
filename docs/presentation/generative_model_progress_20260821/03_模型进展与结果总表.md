# 模型进展与结果总表

> 实验语义提示：SemlaFlow/MiDi 的 checkpoint 用于从噪声联合生成 graph+3D；当前 UAE
> checkpoint 是“已知 graph+3D → latent → graph+3D 重构”的 autoencoder。既往实验均未把
> `Target_PG` 输入模型。tier-1 只是单分子记忆 Gate，`PASS_EXECUTION` 也不等于质量通过。
> 完整设计、输入输出和阈值见
> [08_三模型实验设计与判定口径.md](08_三模型实验设计与判定口径.md)。

## 2. SemlaFlow

### 已完成

- 官方源码接入、环境、CPU/CUDA forward。
- 官方 GEOM checkpoint 的原域 sampling smoke。
- COF tier-1 分阶段 overfit，比较 raw/EMA、不同积分步和 bond-loss 方向。
- 保存生成报告、评测报告、checkpoint 和哈希。

### 结论

模型权重本身可用，但 COF 迁移时生成化学质量不稳定。出现过对训练 SMILES 的记忆信号，
却不能稳定保持 sanitize/connected；继续增加相同步数会混淆“loss 下降”和“生成质量改善”。

## 3. MiDi

### 已完成

- 官方源码与独立 `env_midi`；PyTorch 2.0.1+cu118、PyG 2.3.1。
- 审计 GEOM/TABASCO 数据兼容性，构建近似 GEOM statistics。
- 5-seed 与 100-sample zero-shot。
- COF tier-1、低学习率、timestep-stratified、Min-SNR/bounded-SNR 对照。
- 固定输入 deterministic validation audit。

### 结论

官方 checkpoint 在近似原域有明显可用性，但 COF fine-tuning 的改善覆盖不足。最终 loss 均值
相对 official 改善约 1.52%，却只在一半 timestep 和 43.75% cases 获胜，未证明更新具有
稳定迁移价值。

## 4. UAE-3D / UDM-3D

### U1：兼容性和工程接口

- 2,530 条元素词表兼容；2 条 Sn 记录严格排除，不映射。
- 排除非零 charge/radical 后，官方三头严格兼容 subset 为 2,242。
- 官方 bridge、105 原子往返、CPU/CUDA forward/backward、排列等变、checkpoint/resume 通过。
- 官方 decoder 没有 formal-charge/radical heads，不能代表完整 canonical schema。

### U2 tier-1

- 原始 objective 到 1,024 步仍未通过。
- balanced bond + deterministic coordinate auxiliary 改善明显。
- coordinate refinement 最终 atom/bond exact、sanitize、connected 均通过，RMSD
  `0.048132 Å`，正式放行 tier-4。

### 键图修复分支

- bond-focused refinement：present accuracy 可到 89.86%，但仍 2/4 exact 且坐标回退。
- hard-pair PCGrad：none 提升，present 从 85.14% 降至 57.43%，停止。
- hierarchical head：把 self/existence/type 分离；raw wrong pairs 119→181，threshold 漂移。
- global threshold：在 32 分子 validation 上仍 0/32 bond exact，停止后处理路线。
- capacity probe：post-GELU validation existence AUC `0.88796`、balanced accuracy
  `0.80041`，高于官方共享 head 的约 `0.727`；证明存在信号但不证明 exact 可达。

### 最终 Gate A（只读收尾）

Gate A 在运行前冻结：step-3008 UAE 权重只读；128 IID-train 拟合 probe 和全局 threshold，
原样迁移到 32 IID-validation；test/Core-OOD 未使用。非线性 random-Fourier probe 的
transfer AUC 为 `0.88977`（门槛 `0.90`），macro balanced 为 `0.80934`（门槛
`0.82`）；相对线性 macro 只增加 `0.00893`（门槛 `0.01`），tier-4 same-panel 仍为
`0/4` existence exact。最终状态 `FAIL_GATE_A_STOP_UAE_BRANCH`，因此不执行 Gate B。

这不是“特征完全没有信号”：minimum balanced `0.67956`、none `0.75932`、present recall
`0.88299` 均过线；但证据强度不足以再授权一个 decoder 微调分支。项目按预案转入
`known graph + Target_PG → 3D`。

## 5. 项目整体已经获得的资产

- 可复现的 canonical/symmetry 数据包。
- 三套模型环境和锁定源码。
- 模型无关 adapter、固定 split 和统一 evaluator。
- 一整套区分 execution、engineering、quality 的 Gate 体系。
- 明确的负结果：直接联合生成中，稀疏键图比原子/坐标更难迁移。
- 可复用的正结果：UAE 特征包含键存在性信号，当前 3D 坐标重构可以达到较低 RMSD。

## 6. graph + Target_PG → 3D 的 G2 结果

首个 G2 checkpoint 输入 immutable sparse graph、noisy coordinates、noise sigma 和
`Target_PG`，输出只包含 centered clean coordinates；它不预测 graph/SMILES。146,884 参数
的 4 层 E(3)-equivariant denoiser 已通过旋转、平移、原子排列和 exact-resume 工程测试。

冻结 tier-1 在单个 C2 分子、8 个固定 `σ=0.15 Å` 噪声实例上运行。step 512 与唯一一次
预注册 step-2,048 续训均只失败 absolute RMSD：最终 raw/projected mean 为
`0.19252/0.12663 Å`，而 Gate 为 `≤0.08/≤0.05 Å`。8/8 改善、碰撞、compatible 和
stored-operation residual 全通过。按预注册规则不再延长此 4 层 sparse-only 架构；下一
分支必须扩大非键/全局几何感受野。详见
[10_Graph_PG_3D_G2_Tier1结果.md](10_Graph_PG_3D_G2_Tier1结果.md)。

G2.2 已按预注册 C2 tier-1 完成：6 层、1,145,970 参数，bonded/local/global 三通道独立
归一化，并新增 all-pair distance 与局部 angle 监督。同一步 1,024 的 raw/projected RMSD
为 `0.18571/0.12376 Å`，是当前三个 graph-conditioned 架构中最好，但未过绝对门槛，故
不运行两 C2 + 两 C3 的 tier-4。

## 7. Orbit force-field F0/F0.1

canonical graph 的严格 RDKit 转换与覆盖审计已经完成：UFF 为 `2532/2532`，MMFF94s 为
`2497/2532`；2 个 Sn 分子均保持原子序数 50，UFF 支持而 MMFF 不支持。初始 F0 在固定
200 iterations 下只失败 optimizer success。预冻结的唯一 F0.1 将预算增至 500，其余输入、
目标和阈值不变，最终 10/10 checks 通过：bond ratio `0.02743`、collision-free `0.91667`、
coordinate ratio `0.65648`、operation error `2.89e-7 Å`。当前已放行 initial-conformer
interface，但这仍不是新 graph/SMILES 生成。详见
[19_Orbit_Force_Field_F0_F01结果.md](19_Orbit_Force_Field_F0_F01结果.md)。

随后确定性坐标导出与 `env_cof` 独立 pymatgen 复核显示：candidate analyzer 48/48 成功，
但 compatible 为 44/48。4 个失败集中在 package 1490 的中/高噪声碰撞输出，actual PG 为
C1。因此不直接进入 ETKDG，先做一次只针对该失败模式的短程排斥修复。详见
[20_F01坐标归档与点群独立审计.md](20_F01坐标归档与点群独立审计.md)。

`0.76520 Å`，最大 bond MAE `0.008115 Å`，stored-operation error `1.40e-7 Å`；独立
pymatgen 4/4 为 C2 exact/compatible。正式状态

和 F0.2 后端选优。E0 为 4/4 compatible；扩展 E1 的 24 C2 + 8 C3 达到 128/128 ETKDG

## 8. Graph action E3-A / E3-B

E3-A 使用严格 graph-only 输入，从元素/电荷/自由基/稀疏键和 `Target_PG` 确定性恢复 C2/C3
automorphism、permutation 与 orbits。开发域 2,232/2,232 全部恢复并通过完整显式 H graph
验证，Sn 2/2；mean moved-atom fraction 为 `0.995432`。恢复 action 与 stored action 逐项
相等仅 980/2,232，这是高对称 graph 多个合法子群 action 的非唯一性，不是 graph-action
失败。

E3-B 把 recovered action 接入冻结 E2 后端。16 分子 stress panel（C2/C3 各 8、含 2 Sn
和两个高搜索 C3）的 64/64 候选成功，最小 pair distance `1.043290 Å`、最大 bond MAE
`0.039498 Å`；独立 pymatgen analyzer/compatible 为 16/16、exact 11/16，无 C1。正式状态
`PASS_GRAPH_ACTION_E3B_RECOVERED_ACTION_TO_3D`。因此 known graph 的 action gap 已关闭；
下一主缺口为 Target_PG-conditioned novel 2D graph。详见
[24_Graph_Action_E3A_E3B结果.md](24_Graph_Action_E3A_E3B结果.md)。
