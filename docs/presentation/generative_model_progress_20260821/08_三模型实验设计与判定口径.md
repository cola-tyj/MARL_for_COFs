# 三模型实验设计、checkpoint 语义与判定口径

本文回答三个容易在汇报中混淆的问题：每个模型实际吃什么、输出什么；`tier-1` 究竟测了
什么；一个 checkpoint 为什么被判为 passed 或 failed。所有结论均针对本项目 COF 迁移，
不等同于论文原域结论。

## 1. 共同实验框架

### 1.1 为什么使用 `1 → 4 → 32 → dataset`

分级实验不是把 1/4/32 个分子当作最终训练集，而是逐层定位故障：

| 层级 | 诊断问题 | 允许得出的结论 | 不允许得出的结论 |
|---|---|---|---|
| tier-1 | 模型和 adapter 能否记住一条固定分子 | 接口、objective 和优化链路是否有基本学习能力 | 泛化、条件生成能力 |
| tier-4 | C2/C3/S4/D6h 各一条时，多个尺寸/元素/点群能否同时重构 | 小集合多任务冲突、整分子 exact 上界 | 对 IID validation 或新分子的泛化 |
| tier-32 | 固定分层小面板能否稳定训练并保持化学质量 | 是否值得进入 dataset-level 微调 | 全数据或 Core-OOD 最终效果 |
| dataset | 固定 train/validation split 上训练和选择 checkpoint | IID 泛化和后续 PG 条件化候选 | 未经 test/Core-OOD 审计的最终结论 |

所有 tier 使用 canonical 分子图和 3D 坐标；`Target_PG` 在既往三个基座筛选实验中还没有
作为模型条件输入。此前验证的是“通用 3D 分子建模/重构能力”，不是“指定点群生成”。

### 1.2 三种状态必须分开

- `PASS_EXECUTION`：程序跑完、梯度有限、产物和 checkpoint 可读，只是工程通过。
- `PASS_*_TIER/GATE`：预先冻结的模型质量阈值全部满足，才允许进入下一层。
- `PENDING_MORE_TRAINING`：运行有效但质量未达标；它既不是通过，也不自动授权无限延长。
- `FAIL_*_STOP*`：必要条件已经失败，按冻结协议停止对应分支。

后处理修复、训练集上的 loss 下降、某个随机 seed 成功，都不能单独替代严格 Gate。

## 2. SemlaFlow 实验设计

### 2.1 模型输入、训练目标和采样输出

SemlaFlow 是原子类型、形式电荷、full-pair 键类别和 3D 坐标的联合 flow-matching 模型。

```text
训练输入：插值时刻 t + 噪声/插值后的 atom、charge、bond、coordinates
监督目标：真实分子的 atom、charge、bond 与坐标流/去噪目标
模型输出：atom logits、charge logits、bond logits、3D coordinate/vector prediction
采样输出：从噪声积分得到的完整全原子 3D 分子（图和坐标都重新生成）
```

因此它的生成 checkpoint 不是“给一个 SMILES 输出构象”。采样时只指定原子数等批次条件，
模型同时决定元素、键和坐标。`Target_PG` 未输入模型。

### 2.2 tier 设计

| tier | package index | 设计理由 |
|---:|---|---|
| 1 | `1600` | C2、32 atoms、净电荷 0；测试单分子记忆 |
| 4 | `1600, 1274, 53, 2525` | C2/C3/S4/D6h 各一条；`53` 含 Si |
| 32 | 冻结 `ordered_indices` | C2 24、C3 6、S4 1、D6h 1；原子数 9–87 |

tier-1 从官方 GEOM `200epochs.ckpt` 初始化，训练 256 steps，初始学习率 `3e-4`，step 128
后改为 `1e-4`，每 64 steps 保存一次。

### 2.3 checkpoint 保存什么、如何使用

每个阶段 checkpoint 保存 SemlaFlow 模型权重、EMA 权重、optimizer/global step 和身份字段。
训练审计在同一冻结插值 tensor 上比较 loss、atom/charge/bond accuracy、categorical exact 和
坐标误差；生成审计则分别用 raw 与 EMA 权重、固定 5 seeds、100 integration steps 从噪声
采样。换言之：fixed-tensor reconstruction 回答“网络有没有拟合”，native sampling 回答
“checkpoint 是否真的能生成可用分子”。

### 2.4 pass/fail 依据

- 正面证据：step 128 raw 的 5 个样本中 2 个 sanitize valid，且 2 个都精确命中训练
  SMILES，证明 adapter 和模型存在单分子记忆能力。
- 必要失败：四个 checkpoint 共 20 个 raw 样本只有 5 个 valid；失败集中于过价与
  Kekulize，且随 step、EMA、categorical noise 改变不稳定。
- 全局 bond×2、target-present CE 和 incident-bond auxiliary 均未提高 native raw Gate。
- 后处理能把部分样本 sanitize 不能算模型原生通过。

所以最终状态为 `FAIL_GATE2_SWITCH_TO_MIDI`：失败的是 COF 原生联合采样稳定性，不是代码
执行，也不是官方 GEOM checkpoint 的原域能力。

## 3. MiDi 实验设计

### 3.1 模型输入、训练目标和采样输出

MiDi 也是图和坐标的联合 diffusion，但离散 atom/charge/edge 与连续 position 采用各自
noise process。

```text
训练输入：timestep t + 加噪后的 dense atom X_t、full-pair edge E_t、charge_t、pos_t
监督目标：clean atom/edge/charge 类别和 x0 coordinates
模型输出：clean-category logits 与 position prediction
采样输出：经过 500 个 reverse steps 的完整全原子分子图和 3D 坐标
```

噪声转移还依赖 node-count、atom、bond、charge marginals。官方 checkpoint 不包含这些
数据统计，因此“权重严格加载”和“官方生成分布完整复现”是两个不同实验条件。
`Target_PG` 同样未作为输入。

### 3.2 tier 与 checkpoint 设计

MiDi 使用与 SemlaFlow 相同的 tier-1/tier-4 indices，另行生成和校验自己的数据包/hash。
模型配置为官方 12-layer、500 diffusion steps、显式 H、marginal transition。实验先比较
随机初始化，再比较官方 GEOM checkpoint 初始化；训练 checkpoint 保存模型、optimizer、
step、数据/统计/split hash 和 RNG/配置身份，采样时严格绑定相同 statistics hash。

最终低学习率 transfer 诊断不是只看随机 training loss，而是冻结 32 个 validation cases：
4 个分子噪声实例 × 8 个 timesteps（1/25/50/100/200/300/400/500），对 official 与各阶段
checkpoint 计算相同 atom/edge/charge/position total loss。

### 3.3 pass/fail 依据

先区分三个结论层次：

1. 官方权重可用：近似 GEOM statistics 下，100 个 zero-shot 样本得到 74 valid、94
   connected、0 collision，因此通过“原域近似可用性诊断”。
2. optimizer 不立即破坏权重：`lr=1e-6` 的 step-1/64 采样保持性通过，只授权继续短程
   tier-1，不授权 tier-4。
3. COF 迁移是否稳定：最终 bounded sqrt-Min-SNR checkpoint 必须同时满足：
   mean total-loss ratio ≤ `0.99`、32 cases 中至少 `60%` 优于 official、8 timesteps 中至少
   `75%` 优于 official，并且所有 loss/身份检查通过。

实际 mean ratio `0.98482` 通过，但只改善 `14/32=43.75%` cases 和 `4/8=50%`
timesteps。因此 deterministic 必要条件失败，按协议不再用采样结果“补救”，状态为
`FAIL_BOUNDED_SNR_DETERMINISTIC_GATE_STOP_BEFORE_SAMPLING`。

## 4. UAE-3D / UDM-3D 实验设计

### 4.1 当前训练的其实是 autoencoder reconstruction

目前实验只训练 UAE-3D，不是 UDM latent generator：

```text
checkpoint 输入：已知真实 atom graph、edge graph、3D coordinates
encoder 输出：每个原子的 z_mean / z_log_var
decoder 输出：atom logits、N×N bond logits、重构 3D coordinates
checkpoint 用途：把给定分子压缩后重构；不能从 Target_PG 单独生成新分子
```

官方 UAE 没有 formal-charge/radical decoder heads，词表也没有 Sn。本项目只在 2,242 条
严格三头兼容 subset 上讨论后续微调；Sn 从未映射成 C 或 Si。只有 UAE 重构通过，才有
资格训练 UDM 来学习 latent 分布。

### 4.2 UAE tier 设计

| tier | package indices | 用途 |
|---:|---|---|
| 1 | `864` | 10 原子单分子全原子重构 |
| 4 | `864, 1135, 1114, 862` | 四点群各一条，并含大小/键图压力样本 |
| 32 | 固定 UAE-compatible 面板 | 小规模迁移 Gate；从未获准进入 |

训练 checkpoint 保存 UAE model state、optimizer、step、tier package indices、official source
commit、dataset/package/split fingerprint 和配置。训练时输入真实图和坐标；报告中的
`atom_exact`、`bond_exact`、RMSD 都是 decoder reconstruction 指标，不是自由采样指标。

### 4.3 指标如何判定

- `atom_exact=k/n`：每个分子的所有 atom class 都正确；计数通过的分子数。
- `bond_exact=k/n`：每个分子的全部 unique off-diagonal pair（包括 none）都与真值一致；
  一个 pair 错误就使该分子失败。这是项目重构 Gate，不是 UAE 论文中的同名官方指标。
- `coordinate_rmsd_max`：按分子计算坐标 RMSD 后取面板最大值；tier-1 门槛为 `≤0.05 Å`。
- `sanitize/connected`：把预测 atom/bond 解码为 RDKit 分子后严格检查。
- `PASS_EXECUTION` 只说明训练正常；只有以上预冻结 quality checks 全真才是 `PASS_U2_TIER`。

tier-1 最终 atom/bond/sanitize/connected 全部通过，RMSD `0.048132 Å`，所以准入 tier-4。
tier-4 到 step 3,072 为 atom 4/4、bond/sanitize/connected 2/4、RMSD `0.14220 Å`；继续
head-only 修复后正式 64-step pilot 反而为 0/4 bond/sanitize/connected，故关闭该分支。

### 4.4 Gate A 与 Gate B 的角色

- Gate A：冻结 step-3008 UAE 权重，只训练很小的线性/非线性 probe，检查 hidden pair
  representation 是否含可迁移的 bond-existence 信息；128 IID-train 拟合，32 IID-val
  原样迁移，并做 tier-4 same-panel capacity 上界。它不是 UAE 微调。
- Gate B：只有 Gate A 通过时才值得做的“冻结 encoder + 小 decoder”可选验证。
- 无论 Gate A 结果如何，Gate B 都不再阻塞新主线；下一主线固定为
  `known graph + Target_PG → 3D coordinates`。

Gate A 的门槛、protocol hash 和最终结果记录在
`generative_model/smoke/reports/uae3d_gate_a_protocol_v1.json` 与
`uae3d_gate_a_v1.json`，不能看完结果后修改门槛。

最终结果为 `FAIL_GATE_A_STOP_UAE_BRANCH`：nonlinear transfer AUC `0.88977 < 0.90`、
macro balanced `0.80934 < 0.82`、相对 linear macro 增益 `0.00893 < 0.01`，tier-4
same-panel existence exact `0/4 < 4/4`。minimum balanced、none accuracy、present recall
虽分别为 `0.67956/0.75932/0.88299` 并通过各自门槛，仍不能覆盖四项必要失败。因此不执行
Gate B，转入 graph+PG→3D。

### 4.5 C2/C3 只读分层验证

tier-4 中完整重构的两条恰好是 C2/C3，但同时只有 10/9 个原子；S4/D6h 失败样本有
49/72 个原子。因此不能把 same-panel 2/2 解释为点群优势。后续冻结 step-3008，在 Gate A
原 IID-validation 中固定 24 C2 + 6 C3，使用 official `z_mean + argmax` 重构；不更新权重、
不拟合 threshold，并按原子数分层。

结果为 atom/bond/connected/PG-compatible/joint success 全部 `0/30`，sanitize `5/30`、
collision-free `8/30`，坐标 RMSD mean/max `2.033/5.654 Å`。即使 `≤16` 原子层也为
0/3 exact/joint。状态为
`UAE_C23_READONLY_WEAK_RECONSTRUCTION_EVIDENCE_KEEP_BRANCH_CLOSED`。这证明 tier-4 的
C2/C3 成功是训练面板记忆，不能迁移为 C2/C3 重构或条件生成能力。

## 5. checkpoint 结论速查

| checkpoint | 输入 | 输出/用途 | 已证明 | 没有证明 |
|---|---|---|---|---|
| SemlaFlow COF tier-1 | noise/interpolated graph+3D+t | 从噪声联合生成 graph+3D | 单分子记忆信号 | 稳定有效生成、PG 条件生成 |
| MiDi official/COF transfer | noisy dense graph+3D+t | reverse diffusion graph+3D | 官方权重近似原域可采样 | 稳定 COF 迁移、PG 条件生成 |
| UAE step-3008 | 已知真实 graph+3D | latent 与 graph/3D reconstruction | atom/coordinate 强，小集合 2/4 完整重构 | 新分子生成、Target_PG 控制 |
| UAE Gate A probe | frozen UAE hidden pair features | bond-existence diagnostic scores | 仅表示可读出性 | 新 molecule decoder 或生成能力 |
| UAE C2/C3 read-only | 已知真实 graph+3D，冻结 step-3008 | 30 个 IID-val reconstruction + PG 复算 | 独立 C2/C3 上为弱重构证据 | Target_PG 控制或微调准入 |

因此汇报中不能把 UAE reconstruction checkpoint 画成 `Target_PG → molecule`。下一阶段首先
实现的是 `known graph + Target_PG → 3D`，它把固定真实键图作为条件，只生成坐标并用
symmetry operations/orbits 验收。
