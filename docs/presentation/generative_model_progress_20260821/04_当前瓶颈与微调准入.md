# 当前瓶颈与微调准入

## 1. 已完成的是诊断性微调

项目已完成 SemlaFlow/MiDi tier-1 和 UAE 1/4 分子重构/refinement；尚未做过的是在
2,242/2,532 条数据上的 dataset-level 条件微调。`PASS_EXECUTION` 只代表程序和 checkpoint
链路正常，不等于获准扩大训练。

## 2. UAE 为什么不再扩大

UAE tier-1 已通过，但 tier-4 主分支最高只有 2/4 完整键图；explicit-head 正式 pilot 为
0/4 bond exact/sanitize/connected。最后一次 Gate A 不是继续训练 UAE，而是冻结 step-3008
权重做表示上界审计：

| Gate A 指标 | nonlinear 结果 | 冻结门槛 | 通过 |
|---|---:|---:|:---:|
| IID-transfer ROC-AUC | 0.88977 | ≥0.90 | 否 |
| macro balanced existence | 0.80934 | ≥0.82 | 否 |
| minimum balanced | 0.67956 | ≥0.65 | 是 |
| none accuracy | 0.75932 | ≥0.75 | 是 |
| present recall | 0.88299 | ≥0.75 | 是 |
| macro gain over linear | 0.00893 | ≥0.01 | 否 |
| tier-4 existence exact | 0/4 | 4/4 | 否 |

probe 与输出均有限、source 指纹不变；失败不是工程错误。按运行前协议，只要任一必要检查
失败就不执行 Gate B。因此 UAE/UDM 不进入 tier-32、dataset-level fine-tuning 或 PG
conditioning，状态为 `FAIL_GATE_A_STOP_UAE_BRANCH`。

## 3. 现在何时可以开始微调

“微调准入”已经换到新的 coordinate-only 任务：

```text
immutable known graph + Target_PG
                ↓
        predict 3D coordinates
                ↓
symmetry constraint / relaxation / actual-PG validation
```

该任务不重新猜键，所以不再要求模型通过 full-pair `bond_exact`。建议顺序为：

1. G0：严格数据与条件接口，全数据/四点群 batch 审计；
2. G1：固定 1/4/32 面板的非学习/小模型坐标 baseline；
3. G2：graph-conditioned 3D 模型在 32 分子 validation 上过 Gate；
4. G3：只有 G2 通过后，进入 IID-train dataset-level fine-tuning；
5. test/Core-OOD 始终封存到最终评估。

G2 的必要指标应预先冻结：坐标 finite/centroid-zero、collision-free、actual-PG
exact/compatible、target symmetry error、conformer RMSD；graph 本身由条件输入保证
sanitize/connected。

## 4. 当前不是“继续等 UAE”

模型筛选期已经结束。Gate A 提供了收尾结论：UAE feature 有中等 bond-existence signal，
但不足以支持继续投入 bounded decoder branch。当前 G0 已经落地：新增
`GraphPG3DDataset`，输入 canonical sparse graph、`Target_PG` one-hot、target operations、
permutations 和 orbits，监督目标只包含全原子坐标。

G1 已完成并证明 hard projection 只能作为约束层。首个 G2 也已完成：4 层 sparse-bond
EGNN 在 step 512 和预注册 step 2,048 续训均有 8/8 正向改善，但最终 raw/projected RMSD
`0.19252/0.12663 Å` 没有通过 `0.08/0.05 Å`。因此当前不是等待更多相同训练步数，而是需要
扩大 non-bonded/global geometry 感受野；朴素 dynamic full-pair 随后也已验证为弱于 sparse
同一步，因此必须改为 bonded/local/nonbonded 分通道几何聚合。新架构通过 tier-4/32 前
仍不进入全数据微调。
