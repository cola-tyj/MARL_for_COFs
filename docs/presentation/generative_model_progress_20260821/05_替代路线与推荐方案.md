# 替代路线与推荐方案

## 1. 路线比较

| 路线 | 优点 | 主要风险 | 建议优先级 |
|---|---|---|---:|
| 继续 UAE decoder | 已有代码、环境和低 RMSD 坐标能力 | 最终 Gate A 已失败，full-pair 键瓶颈与 schema 不完整 | 停止，不做 Gate B |
| GEOM/QMugs + COF 直接 3D 联合训练 | 大数据提供一般化学和构象先验 | 外部数据无 PG 标签；计算成本高；词表/尺寸/域偏移 | 中 |
| 条件 2D graph → graph-conditioned 3D | 化学图和坐标解耦；避免重新预测键；可复用大规模 2D/3D 数据 | SMILES 不决定点群；需要两个模型和误差传递控制 | **高** |
| template/orbit symmetry-by-construction | 小数据也能保证拓扑/几何对称性；可解释 | 新颖性受模板限制；relaxation 可能破坏 symmetry | **最高优先 baseline** |
| 从头训练端到端 PG-conditioned 3D | 目标最直接 | 2,532 太小、类别极不平衡、优化最难 | 低 |

## 2. 外部数据联合训练的正确方式

不能简单把外部数据和 COF 数据拼接后统一训练一个 `Target_PG` 条件模型，因为 GEOM/QMugs
没有本项目定义下的 target label。建议 curriculum：

### Phase 1：通用预训练

- 2D generator：在 GuacaMol/MOSES/GEOM molecular graphs 上学习 atom/bond/valence。
- 3D conformer model：在 GEOM-Drugs 或 QMugs 上学习 graph → conformer。
- 可先使用 external vocabulary 交集；Si/Sn 等扩展 token 必须显式新增，绝不 fallback。

### Phase 2：COF 域适配

- 使用 2,532 条 canonical 数据进行尺寸、元素和 scaffold 适配。
- 采用 dataset-balanced batch，而不是让外部百万级数据淹没 COF。
- canonical 保留显式 H；模型推荐先使用 heavy-atom view，随后 RDKit 严格补 H 并校验。

### Phase 3：对称性条件微调

- 只用拥有可靠 symmetry annotation 的样本监督 `Target_PG`。
- C2/C3 做主要训练和定量；S4/D6h 使用 oversampling、few-shot 或模板方式。
- 将 operation matrices、permutation/orbits 用于 symmetry loss 或 hard expansion。

### Phase 4：采样与重排

- 生成多个 graph/SMILES 候选和多个 conformer。
- 依次过滤 sanitize、connected、collision。
- 用统一 analyzer 计算 actual PG、exact/compatible 和 symmetry error。
- 不能用 2D PG classifier 的输出替代最终 3D 复算。

## 3. 2D → 3D 是否可行

可行，而且是当前最推荐的路线，但应把第一阶段定义为“生成具有目标对称性潜力的化学图”，
而不是“SMILES 已经具有确定点群”。SMILES 本质上描述 atom/bond connection table，并可包含
局部立体信息；它不包含一套唯一 3D 坐标。同一 graph 可以有多个构象和不同近似点群。

推荐的中间表示比裸 SMILES 更丰富：

- heavy-atom molecular graph；
- `Target_PG`；
- graph automorphism orbit / attachment-site orbit；
- core、linker、substituent 和对称复制次数；
- 可选的构象/手性约束。

最终仍可输出 canonical SMILES 供接口使用，但训练和约束最好在 graph 上进行。

## 4. 推荐实现顺序

### R0：非学习 symmetry-by-construction baseline

复用 `cof_symmetry_pipeline` 的 core/linker/attachment 规则：只生成一个 asymmetric unit，
按 C2/C3/S4/D6h 的 graph action 复制，再做 RDKit sanitize。这样先获得一个可以真正生成新
SMILES 的强 baseline，并为 ML 生成器提供有效候选/增强数据。

### R1：已知 graph → 3D baseline

1. RDKit ETKDG 生成多个构象。
2. 根据 target operations/orbits 做坐标投影或对称约束优化。
3. 使用 MMFF/UFF/xTB（可用时）relax。
4. 统一 analyzer 验收 exact/compatible。

该 baseline 不需要下载大模型，就能回答“给定一个候选 SMILES，现有 pipeline 能否找到目标
点群构象”。

### R2：学习式 graph-conditioned 3D

优先审计 Torsional Diffusion 或 GeoDiff：二者都以 molecular graph/SMILES 为条件生成构象，
不会重新生成化学键。先原始 checkpoint zero-shot，再决定是否用 GEOM + COF fine-tune。
对于高刚性、芳香和对称 COF 构筑单元，GeoDiff 的全坐标建模可能比只优化 torsion 更合适；
两者都必须检查 Si/Sn、显式 H、最大原子数和环体系支持。

### R3：条件 2D generator

- 快速 baseline：SELFIES/SMILES Transformer，先做无条件预训练，再加入 PG token 微调。
- 更严格方案：DiGress/SparseDiff 风格的离散 graph diffusion，直接预测 atom/bond graph。
- 小数据条件：把 `Core`/attachment pattern 与 `Target_PG` 一起作为条件，避免只记住 PG 类别。

### R4：hard-symmetry 3D generator

最终可利用 v2 已保存的 group operations 和 atomic orbits：模型只生成 orbit representative
坐标，再通过 `X_{g(i)} = R_g X_i` 展开其余原子。这样 symmetry 是构造保证，不完全依赖
soft loss。化学键图在 2D 阶段已知，3D 阶段只需解决代表点坐标和 relaxation。

## 5. 推荐决策

主路线建议设为：

```text
template/conditional 2D graph
        ↓
valid graph + Target_PG + graph/orbit metadata
        ↓
graph-conditioned conformer generation
        ↓
orbit-based hard symmetry + constrained relaxation
        ↓
actual-PG exact/compatible validation
```

UAE 最终表示上界/128→32 transfer Gate A 已按冻结协议失败，因此不再投入 decoder 架构
调参，也不执行 Gate B。新主线 G0 接口已通过全 2,532 条审计。G1 hard projection 让
32/32 RMSD 与 bond MAE 改善且精确满足 stored operations，但平均 RMSD `0.16477 Å` 未过
`0.15 Å` Gate；因此 projection 保留为约束层，下一步实现 G2 graph-conditioned denoiser。

## 6. 2026-08-22 当前执行方案：Coordinate Flow Matching

以上 R0–R4 和外部数据 curriculum 全部保留。根据后来完成的 G2.2 与成熟 backbone
Fast-32，当前 R2 不再优先继续审计更多模型，而是固定本地 Semla `EquiInvDynamics`，将
训练任务改回其匹配的 coordinate flow-matching 参数化：

```text
known graph + Target_PG + centered Gaussian prior
        ↓ time-conditioned endpoint flow matching
multi-step ODE coordinate sampling
        ↓ raw geometry/PG audit
optional hard symmetry + constrained relaxation
```

可行性分层为：F0 工程实现高、Fast-32 flow 中高、2,026 条域内 graph→3D 中等、最终
PG→全新 graph+3D 中低。主要优点是固定真实键、真正从 prior 采样、复用成熟 E(3) backbone
和完整 symmetry annotations；主要风险是单构象监督、PG 被 graph 信息掩盖、C2 类别失衡、
显式 H/dense pair 显存，以及新 graph 缺少 atomic permutation/orbit。

停止规则是：不增加第三个 backbone；endpoint flow 只做一个主实验；integrator 与 PG
conditioning 各最多一次有界修复。若 correct-PG 仍不优于 swapped-PG，则回到 R0/R4
的 symmetry-by-construction，而不是继续模型搜索。完整计划见
[13_Coordinate_Flow_Matching计划与可行性.md](13_Coordinate_Flow_Matching计划与可行性.md)。

最终进度：F0 与 Fast-32 工程 Gate 通过，但唯一一次 1,024-step 质量实验以
`FAIL_COORDINATE_FLOW_FAST32_STOP_ENDPOINT_BRANCH` 结束；高噪声 recovery、碰撞、raw analyzer
和 correct-vs-swapped PG 均未过预注册 Gate，因此不做 integrator/condition 修复，不进入
2,026 条长训。

R4 已成为当前执行主线。orbit representative 的 NumPy/Torch 可微展开接口已完成，2,279 条
IID train/validation 严格审计零失败，最大 operation error `6.11e-7 Å`、collision-free 100%。
O0 denoiser 工程 Gate 通过后，唯一一次 512-step O1 也已完成，但 overall/low-noise coordinate
ratio `0.85997/1.01871`、collision-free `0.64583` 未过 Gate，状态
`FAIL_ORBIT_COORDINATE_O1_STOP_DENOISER`。因此不延长、不进入 learned sampler。R4 下一实现改为
orbit-constrained force-field relaxation，把 collision 和局部化学几何交给显式物理约束；
完整记录见 [18_Orbit_Coordinate_O1结果.md](18_Orbit_Coordinate_O1结果.md)。

## 7. 2026-08-22 更新：force-field 后端已通过

严格覆盖审计显示 UFF 支持 `2532/2532`，包括 2 个 Sn 分子；MMFF94s 支持 `2497/2532`，
因此统一后端选 UFF，MMFF 只作有参数样本的诊断。冻结 F0 因 200-step SciPy 收敛标志失败，
但其余质量项全部通过；唯一一次 F0.1 只把迭代预算增至 500，最终 10/10 Gate checks 通过。

这使 R1/R4 的后半段从“建议”变成已验证组件：`known graph + known orbit action + initial
conformer → strict-symmetry relaxed 3D`。下一主缺口前移到 initial conformer 与新 graph 的
automorphism/orbit mapping。先实现 ETKDG/canonical conformer adapter，再决定是否下载或微调
GeoDiff/Torsional Diffusion；不再继续 O1 learned denoiser。

后续独立 pymatgen audit 对上述结论增加了边界：48 cases 中 44 个 compatible，4 个
package-1490 中/高噪声输出因严重碰撞被识别为 C1。冻结 F0.2 只增加非键短程排斥，已将
4 个固定案例全部修复为无碰撞且 C2 exact/compatible；旧 F0/F0.1 状态仍原样保留。由此
解除 ETKDG 前置阻塞。ETKDG 多构象、严格 atom-index/orbit action、F0.2 后端和 independent
analyzer 已继续实现并通过 32 分子 E1：128/128 embedding、32/32 compatible。R1/R4 现在
已有可工作的 known-graph 初始构象链条；下一步先做 dataset-scale C2/C3 覆盖，再以失败率和
成本决定是否值得引入 GeoDiff/Torsional Diffusion。

## 8. 2026-08-24 更新：ET-Flow 独立零样本支路

E2/E3 确定性链条和 E3-C 新 2D graph 主缺口保持不变。新增 ET-Flow 只作为
`known graph → initial conformer` 的替代先验，编号 EF0/EF1，不能写成 E3-C，也不能宣称
ET-Flow 自身接收 `Target_PG`。

EF0-A 的 checkpoint-free strict bridge 已通过：固定 4 个 C2/C3 graph-only 样本、两条 Sn，
canonical explicit-H atom/typed-bond roundtrip 全部 exact；未读取 reference XYZ 或 ETKDG
coordinates，投影最大 operation error `1.88e-15 Å`。官方 `drugs-o3` EF0-B 随后也已通过，
固定 checkpoint SHA `a24ae9…ccb2`，两条 Sn 完成 CUDA forward。32 条 IID-test EF1 已按冻结
协议完成：ET-Flow/ETKDG final compatible 均为 32/32，exact 为 20/32 和 21/32；
raw pair-distance 中位比 0.87261，但相同 F0.2 后 final 比值近乎 1。该支路因而获得
EF2 有界微调评估资格，但没有证明显著超过 ETKDG。完整边界见
[25_ETFlow_ZeroShot与Symmetry_Projection.md](25_ETFlow_ZeroShot与Symmetry_Projection.md) 和
[26_ETFlow_EF1结果与微调评估.md](26_ETFlow_EF1结果与微调评估.md)。
