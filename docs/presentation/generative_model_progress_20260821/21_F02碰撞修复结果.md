# F0.2 有界碰撞修复结果

## 1. 任务边界

F0.2 不是新模型、不是重新训练，也不改写 F0/F0.1 的历史状态。它只处理 F0.1 独立
pymatgen 审计中固定的 4 个失败案例：`cof_001490`、`σ=0.5/1.0 Å`、两个冻结 seed。
test/Core-OOD 未读取。

冻结后保持不变的部分包括：同一 target operation/permutation/orbit action、UFF 主目标、
初始 orbit-symmetric noise、500-step 上限、原子和真实化学键。唯一新增项是所有**非键原子对**
在 `r < 0.8 Å` 时承受

`E_rep = 0.5 × 2000 × (0.8 - r)^2 kcal/mol`。

真实化学键严格排除，不使用元素 fallback，也不修改原 F0.1 optimizer 或报告。解析梯度已用
中心有限差分验证。v1 协议在完成计算后因 `numpy.bool_` 无法序列化而工程中止，未形成正式
结论；v2 只修正标准 JSON 类型和工件版本，力场与 Gate 参数完全不变。

## 2. 预注册 Gate

几何层要求 4/4：有限、总目标不增加、最短原子间距 `≥0.6 Å`、最大 bond-length MAE
`≤0.1 Å`、stored-operation 最大误差 `≤1e-5 Å`，且可接受 optimizer termination 比例
`≥0.75`。几何通过后，必须在独立 `env_cof` 中用 pymatgen `0.3 Å` tolerance 重算，要求
analyzer success 和 `pg_compatible` 都为 4/4。

## 3. 正式结果

| 指标 | 结果 | Gate |
|---|---:|---:|
| collision-free | 4/4 | 4/4 |
| 最小原子间距 | `0.76520 Å` | `≥0.6 Å` |
| 最大 bond-length MAE | `0.008115 Å` | `≤0.1 Å` |
| 最大 stored-operation error | `1.40e-7 Å` | `≤1e-5 Å` |
| 可接受 optimizer termination | 4/4 | `≥3/4` |
| pymatgen analyzer success | 4/4 | 4/4 |
| actual PG | 4/4 为 C2 | 非 C1 |
| PG exact / compatible | 4/4 / 4/4 | compatible 4/4 |

四次优化均由 SciPy 正常收敛，迭代数为 156–172。几何层状态为
`PASS_F02_COLLISION_GEOMETRY_AWAIT_POINT_GROUP_AUDIT`，独立复验后的最终状态为
`PASS_F02_COLLISION_REPAIR_ADVANCE_TO_ETKDG`。

## 4. 能说明什么、不能说明什么

本结果证明：F0.1 的唯一已知失败模式可以在不破坏 orbit 硬对称和局部键长的前提下，用一个
有界非键短程排斥项修复；stored-operation residual 与 independent actual-PG 在修复后也一致。

本结果仍不能说明能够从 SMILES/graph 产生初始 3D，更不能说明能够生成新 SMILES。当前已验证
组件的输入仍是 `known graph + known orbit action + orbit-symmetric initial coordinates`。
