## 一、整体架构

### 设计目标

构建一个**点群对称性可标签化**的 COF 中间体核心分子数据集。每个分子经历"2D 拓扑生成 → 3D 几何嵌入 → 力场松弛 → 对称性验证"四阶段筛选。

### 数据流

```
config.py (模板库: 511 核心 × 77 臂)
    │
    ▼
Stage 1: generator.py          ─── 2D 分子 (SMILES, 拓扑对称)
    │                                方法: ReplaceSubstructs + _cleanup_bridges
    │                                原理: * 位于图自同构轨道的等效位置
    │                                      ReplaceSubstructs 等价替换 → 拓扑对称保持
    │
    ▼
Stage 2: relaxer.py (Embedder) ─── 3D 构象 (含 H, ETKDGv3 坐标)
    │                                方法: ETKDGv3 + 8 种子多构象选优
    │
    ▼
Stage 3: relaxer.py (GeometryRelaxer + SymmetryAnalyzer)
    │                                方法: MMFF94 力场优化 → pymatgen PointGroupAnalyzer
    │                                筛选: EMBED_FAIL / RELAX_FAIL / ENERGY_FAIL / SYMMETRY_BREAK
    │
    ▼
Stage 4: main.py               ─── 分来源 CSV + XYZ
    │
    ▼ 合并、去重、补充几何标签、移除空 XYZ_Path
final_dataset.csv             ─── 当前训练数据集（2,532 分子）
missing_xyz_path.csv          ─── 缺失 XYZ 的隔离记录（45 分子）
rejected_pg_rule.csv          ─── 新点群规则拒绝记录（76 分子）
```

### 核心设计原则

1. **对称性由构造保证**: `*` 位于图自同构轨道的等效位置，ReplaceSubstructs 等价替换 → 2D 拓扑对称 = 核心对称
2. **3D 验证不可省略**: 柔性旋转自由度可导致对称破缺（C₃ → C₁），需 pymatgen 点群验证
3. **模块化可扩展**: 新增核心/臂只需在 `config.py` 添加条目

## 二、Stage 1: 2D 拓扑组合生成

### 负责文件

| 文件 | 作用 |
|------|------|
| `config.py` | 定义核心模板库（CORE_TEMPLATES）和臂库（ARM_LIBRARY） |
| `generator.py` | 组合合成引擎：核心 + 臂 → 完整分子 |
| `generator.py` → `_cleanup_bridges()` | 移除 ReplaceSubstructs 产生的桥接 dummy 原子 |

### 算法步骤

**Step 1: ReplaceSubstructs**
```python
products = AllChem.ReplaceSubstructs(core_mol, query='*', arm_mol, replaceAll=True)
```
核心中所有 `*` 被同一个臂等价替换。产物含有桥接 `*`（degree=2）。

**Step 2: _cleanup_bridges**
```python
# 1. 找出所有桥接 * (atomic_num==0 且 degree==2)
# 2. 降序移除桥接 *
# 3. 邻居索引校正后创建 C-C 直连键
```
移除桥接 `*`，将核心锚点与臂直接连接。

**Step 3: SanitizeMol** — Kekulé 化 + 化合价验证。

### 示例

```
输入: triazine_C3 (*c1nc(*)nc(*)n1) + CHO_ph (*c1ccc(C=O)cc1)
  ↓ ReplaceSubstructs → 33原子, 3个桥接*
  ↓ _cleanup_bridges  → 30原子, 0残留*
  ↓ SanitizeMol       → ✓
输出: O=Cc1ccc(-c2nc(-c3ccc(C=O)cc3)nc(-c3ccc(C=O)cc3)n2)cc1
      2,4,6-三(4-甲酰基苯基)-1,3,5-三嗪, C₃ 对称 ✓
```

## 三、Stage 2: 3D 构象嵌入

### 负责文件

| 文件 | 类/函数 | 作用 |
|------|:------:|------|
| `relaxer.py` | `Embedder` | ETKDGv3 距离几何嵌入 |
| `relaxer.py` | `SymmetryAnalyzer` | pymatgen PointGroupAnalyzer + 惯性张量回退 |

### ETKDGv3 嵌入

- 加氢 → ETKDGv3 随机坐标嵌入 → MMFF94 预优化
- 8 个不同随机种子产生多构象
- 每个构象计算点群后选最佳匹配进入 Stage 3

### 点群分析

- 首选: pymatgen `PointGroupAnalyzer` (tolerance=0.3Å)
- 回退: 惯性张量特征值简并度推断
- 评分体系: 精确匹配(3.0) > 等价类(2.0) > 超群(1.0) > 数值匹配(0.5) > 破缺(-1.0)

## 四、Stage 3: 几何优化与对称破缺筛查

### MMFF94 力场优化

- RDKit MMFF94（默认，有机分子专用）
- 可选: UFF / MACE-OFF23 / GFN2-xTB
- 输出: 最终能量 + 最大原子位移

### 三级淘汰

| 淘汰类型 | 条件 | 含义 |
|------|------|------|
| FAIL_EMBED | ETKDGv3 返回码≠0 | 位阻过大，无法嵌入 |
| FAIL_RELAX | 力场优化异常 | 结构不稳定 |
| FAIL_ENERGY | 能量异常（>1e8 或 NaN） | 力场发散 |
| FAIL_FORCE | 原子位移 > 阈值（默认 5.0 Å） | 几何崩塌 |
| FAIL_SYMMETRY_BREAK | 松弛后点群不匹配目标 | 对称性丢失 |

### 对称破缺检测

```python
_check_symmetry(target_pg, actual_pg):
    if actual_pg in BROKEN_SYMMETRY_TAGS: return False      # C1, Cs, Ci
    if actual_pg == target_pg: return True                   # 精确匹配
    if actual_pg in PG_ALLOWED_ACTUAL[target_pg]: return True
    return False
```

接纳规则按目标族单向判断：C2 接受 C2/C2v/C2h/D2/D2h/D2d；C3 接受
C3/C3v/C3h/D3/D3h/D3d；C4 接受 C4/C4v/C4h/D4/D4h/D4d；S4 仅接受
S4/D2d；D6h 仅接受 D6h。C4 与 S4 不再互相等价。

### 实战案例

**PASS (三嗪+直接醛基)**: 刚性骨架，三个-CHO 到质心距离全等(2.768Å)，夹角 120°，共面性 0.000Å → C₃ₕ。

**FAIL (三苯基苯+直接醛基)**: 核心苯环与外臂苯环间单键旋转，三个臂取了不同扭转角，共面偏差 0.103Å → C₁。

- **核心**: `*` 位于分子图自同构轨道的等效位置（RDKit `CanonicalRankAtoms` 验证）

- **层级核心**: 父核心的每个 `*` 被 C₂ 线性核心替换 → 对称性保持

## 七、层级核心优化

层级核心（414 个）MW 范围 336–2425 Da，直接跑会卡死。实现了4 项优化：

| 优化 | 机制 | 效果 |
|------|------|------|
| MW 预过滤 | `max_heavy_atoms` 阈值，超限分子 Stage 1 后丢弃 | 砍掉过大的 |
| 减少构象尝试 | `num_conformer_attempts` 8→3，大分子→1 | 嵌入耗时 ×0.37 |
| 按大小排序 | 重原子数升序处理 | 渐进收割 |
| 动态调整 | 每个分子根据 n_heavy 独立设置尝试次数 | 精准分配 |

用法: `python main.py --hierarchical --max-heavy 100 --workers 8`
