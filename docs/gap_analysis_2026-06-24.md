## 二、逐项偏差分析

### 2.1 Phase 1 — QM9 预训练

| 规划 | 实际 | 偏差说明 |
|------|------|------|
| RDKit 合法性 > 90% | ✅ 97%（精修法） | 达标，但从纯噪声生成坍缩为 H |
| 唯一性 > 95% | ⚠️ 精修法 100%，纯噪声 5% | 精修法达标，de novo 不达标 |
| KL 散度 < 5% | ❌ 未测 | 遗漏 |
| Attention 机制 | ❌ 禁用 | 全局 softmax NaN，论文可讨论 |

**改进**：补充 KL 散度测试（1h），量化 QM9 原子分布保真度。

### 2.2 Phase 2 — 对称性条件注入

| 规划 | 实际 | 偏差说明 |
|------|------|------|
| 384-dim 条件（sym+conn+FG） | 128-dim（仅 sym） | Core-only 简化，论文可作为"消融"对比 |
| 14 点群 | 16 点群（+D2d, Td） | 扩展更完整 |
| 连接点正确率 > 85% | ✅ 100% | 坐标精修法 Q/R 完整保留 |
| RDKit 合法性 > 75% | ❌ 不适用 | Q/R 占位原子无法 RDKit 验证（论文 limitation） |
| 数据增强 194→2000 | 83→5000 | 数据量更充足 |
| 两阶段微调 | ✅ Stage A+B | 正常 |

**改进**：
1. 增加 Core 数据多样性（依赖 pycofbuilder 扩展核心库）
2. 量化精修 Core 与模板的几何差异（RMSD, 二面角变化）
3. 补充对称一致性量化测试（生成 Core 的点群 vs 条件点群）

### 2.3 Phase 3 — COF 构件生成器

| 规划 | 实际 | 偏差说明 |
|------|------|------|
| 5 层过滤 (原子→RDKit→对称→连接→组装) | 3 层 Core 过滤 | 简化但不影响核心功能 |
| 端到端通过率 ~16% | Core 过滤 53% | 层数少所以率高 |
| COF 组装成功率 | **37.5%** (3/8) | **偏低，主要差距** |
| CJSON 导出 | XYZ/CIF 为主 | CJSON 未用 |
| COFBBGenerator | CoreGenerator | 重构 |

**改进（高优先级）**：
1. **提升 COF 组装率**：预验证 697+ Core 组合 → 过滤白名单 → 成功率预期 > 80%
2. 补充 CJSON 导出（用于与其他工具交互）
3. 生成更多样的 COF（多种拓扑 × 多种 Core 组合）

### 2.4 Phase 4 — MARL 集成

| 规划 | 实际 | 偏差说明 |
|------|------|------|
| 3-Agent 设计 | 多次迭代（3→2→3+RND） | 探索中，架构已确定 |
| Self-Play 闭环 | ❌ 未实现 | 计划但未实施 |
| 真实 N₂ reward | ✅ 40 COF 预计算 | 40/55 覆盖 |
| RND 探索 | ✅ 已实现 | 规划外新增 |
| GCMC 在线模拟 | ❌ 未实现 | 用 predictor 替代 |

**改进（中优先级）**：
1. 预验证动作空间（白名单 Core 组合）→ 预计成功率 72%→85%+
2. Self-Play 闭环：好 COF → Core 加入训练集 → 微调扩散模型
3. 全覆盖 N₂ lookup（55 设计全部预测）

### 2.5 Phase 5 — 实验评估

完全未开始。需要：

1. **基线方法对比**：
   - 固定词汇表 MAPPO（现有 mappo/ 系统）
   - 随机搜索基线
   - 纯扩散生成（无 MARL 优化）
   - 遗传算法

2. **消融实验**：
   - 对称性条件 on/off
   - FiLM vs 拼接条件
   - 扩散步数 100/250/500/1000
   - Agent 数量 2 vs 3
   - RND 探索 on/off
   - 精修 vs de novo

3. **评估指标**：
   - N₂ 吸附量（均值、Top-10）
   - 合法性、多样性、新颖性
   - 计算效率

## 四、与原规划的核心一致性

**偏离但合理的决策**：
1. Core-only 生成（vs 完整 BB）— 论文可论证"分而治之"优势
2. 禁用 Attention — 论文可讨论数值稳定性 vs 模型容量
3. 精修法 vs de novo — 论文 limitation 诚实讨论

**需要补的核心差距**：
1. Self-Play 闭环 — 论文核心亮点
2. COF 组装成功率 — 需达到 >50% 才有说服力
3. Phase 5 对比实验 — 论文实验章节

**建议下一步**：先完成 COF 组装率提升（🔴#1），然后实现 Self-Play（🔴#2），最后 Phase 5 实验（🟡#6）。
