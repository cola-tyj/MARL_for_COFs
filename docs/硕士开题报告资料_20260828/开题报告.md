## 一、课题名称与研究主线

**主标题**：面向 COF 构筑单元的指定点群三维分子生成方法研究

**副标题**：从对称数据构建、约束生成基线到轨道空间条件流模型

**一句话研究主线**：

```text
对称 COF 分子数据构建
        ↓
known graph + Target_PG → 3D 的可行性验证（our_ET_Flow 组合路线）
        ↓
在轨道代表元空间中训练 symmetry-by-construction 坐标流
        ↓
扩展为 Target_PG → quotient graph/action → symmetric 3D 的联合生成模型
```

**研究对象界定**：本课题研究的是"具有指定分子点群的 3D 构筑单元"，即可作为 COF 组装前体的
离散有机分子，**不涉及**完整周期 COF 晶体的空间群生成。

## 二、研究背景与意义

### 2.1 COF 构筑单元设计与对称性

共价有机框架（Covalent Organic Frameworks, COFs）由具有特定连接数、拓扑和空间构型的有机
构筑单元组装而成。构筑单元的分子对称性直接决定：

1. **连接位点的等价性**——同一轨道上的官能团是否化学等价；
2. **网络拓扑**——C₂/C₃/C₄/H₆ 连接数决定二维六方、四方或三维网络；
3. **孔道形貌与材料功能**——对称破缺会导致缺陷和性能下降。

因此，若能在分子设计阶段按指定点群（C₂、C₃、S₄、D₆ₕ 等）生成候选构筑单元，就能把化学空间
搜索从"随机生成后筛选"转化为"按结构先验定向生成"。当前随机生成后筛选高对称分子的效率
极低：前期外部数据库挖掘实验表明，随机类药物分子中满足目标对称性的比例仅约 **0.0057%**。

### 2.2 三维分子生成的三类约束

三维分子生成同时包含三类约束：

1. **化学约束**：元素、价态、形式电荷和化学键必须合法；
2. **几何约束**：键长、键角、非键距离和构象能量必须合理；
3. **群论约束**：目标点群的每个空间操作必须对应一个同元素、同化学环境的原子置换。

传统 SMILES/2D 图生成主要解决第一类约束；一般 3D 等变生成模型主要处理旋转、平移和排列
等变性，却**不自动保证**一个具体分子具有用户请求的 C₂、C₃、S₄ 或 D₆ₕ 点群。本课题的研究
空白正位于这两者之间。

### 2.3 必须区分的两种"对称"

**E(3)/SE(3) 等变性**：若将整个输入分子旋转或平移，模型输出随之旋转或平移：

$$f(RX+t)=R f(X)+t$$

这保证模型不依赖实验室坐标系，但**不保证输出分子自身具有 C₃ 轴**。

**分子点群对称性**：对于指定点群中的每个操作 $g$，需要存在空间矩阵 $R_g$ 和原子置换 $p_g$，
使得：

$$X R_g^T = X[p_g]$$

这是"分子内部在某些非平凡变换下保持不变"，与模型对整体旋转等变不是同一个问题。

> **核心论断**：E(3)-equivariant model ≠ point-group-conditioned model。等变是必要条件，
> 不是指定点群保证。

### 3.3 文献空白与本项目定位

现有分子模型多解决 E(3) 等变、属性条件或构象生成；晶体模型已有显式空间群表示，但针对
**孤立有机分子的"指定 Schoenflies 点群 + 化学图自同构 + 轨道坐标生成"仍缺少成熟通用方案**。

晶体空间群包含平移和 Wyckoff position；孤立分子点群只包含保持一个固定点不动的有限 O(3)
操作，且需额外处理化学图自同构、显式 H、柔性构象、子群/超群 compatibility 等分子特有
问题。因此不能直接搬用晶体模型，但可迁移"quotient/asymmetric unit + group action +
expansion"的表示思想。

## 四、研究目标与任务分层

### 4.1 任务三层次

| 层次 | 输入 | 输出 | 当前状态 |
|---|---|---|---|
| 构象生成 | known graph | 3D conformer | 官方 ET-Flow 提供初始先验 |
| **对称构象生成** | known graph + Target_PG | PG-compatible 3D | our_ET_Flow 组合路线已验证 |
| 对称分子生成 | Target_PG/性质 | novel graph + PG-compatible 3D | 尚未实现，扩展目标 |

### 4.2 硕士阶段目标（两级）

1. **主目标**：实现不依赖生成后 hard projection 的
   `known graph + Target_PG + graph action → raw symmetric 3D`；
2. **扩展目标**：实现 `Target_PG → novel valid quotient graph/action → symmetric 3D`。

这样的表述既承接当前成果，又避免把"直接生成新分子图"作为必须一次解决的单点高风险任务。

### 4.3 任务形式化

主线任务：给定分子图 $G=(V,E,\mathbf{a},\mathbf{b})$ 和目标有限点群 $P$，学习条件分布
$p_\theta(X \mid G, P)$，使生成坐标满足化学几何合理性和 $P \preceq \mathrm{ActualPG}(X)$。

扩展任务：进一步学习 $p_\theta(G, X \mid P, \mathbf{c})$，其中 $\mathbf{c}$ 可以是分子大小、
连接位点、元素组成或目标性质。

## 五、核心科学问题与研究假设

### 5.1 科学问题

**科学问题一：如何表示"指定点群"**——仅使用 C₂/C₃ one-hot 容易被网络忽略，也不能表达群
操作与原子等价关系。需要把点群表示为抽象群特征（群阶、生成元、乘法表、共轭类、子群格）、
表示论特征（特征标表、不可约表示）、空间操作特征（矩阵、行列式、迹、旋转角）和原子置换
特征（循环类型、轨道、stabilizer）。

**科学问题二：如何同时保证对称性和化学几何**——对称投影能精确满足群作用，却可能缩短键长
或制造碰撞；自由几何优化能降低能量，却可能破坏点群。模型必须在**对称子空间内**学习或优化。

**科学问题三：如何实现真正的条件可控性**——同一高对称结构可能同时兼容 C₂ 和 C₃。必须设计
相同图、相同随机初态、只替换 Target_PG 的反事实实验，判断输出是否对不同条件产生可区分响应。

**科学问题四：有限对称数据如何训练生成模型**——当前数据只有 2,532 条且类别严重不平衡。
合理方案是通用 3D 数据预训练 + 对称数据微调 + 平衡采样与 OOD Gate。

### 5.2 研究假设

- **H1**：在每个生成时间步将状态限制在目标群不变子空间，比只添加 PG embedding 或 soft
  symmetry loss 能获得更高的 raw PG-compatible rate；
- **H2**：在 orbit representative space 中生成，能够降低坐标自由度（当前数据平均 DOF ratio
  ≈ 0.47）并减少同轨道原子间的不一致；
- **H3**：大规模通用构象预训练 + 小规模对称数据微调，比直接在 2,532 条数据上从头训练更稳定；
- **H4**：quotient graph/orbit grammar 能比"先任意生成图、再筛选 automorphism"更高效地产生
  满足指定点群的 novel graph；
- **H5**：加入 swapped-PG 对比目标，可减少 C₂/C₃ 请求坍缩到共同超群的现象。

### 6.2 our_ET_Flow 组合路线（约束生成基线）

当前已实现并验证的路线解决 `known graph + Target_PG → PG-compatible 3D`：

```text
known graph → frozen ET-Flow drugs-o3（4 raw conformers）
     ↓
Target_PG → graph action {R_g, p_g, orbit}（typed graph automorphism 恢复）
     ↓
PCA×24 orientation search
     ↓
Reynolds hard projection（X→Π_G(X)）
     ↓
orbit-constrained UFF + repulsion（F0.2，仅优化轨道代表元）
     ↓
严格几何 Gate + 独立 actual-PG audit
     ↓
final.xyz
```

**四路线配对消融（32 条冻结面板，冻结数字）**：

| route | PG-compatible | collision-free | mean bond MAE |
|---|---:|---:|---:|
| ETKDGv3 best-of-4 | 9/32 | 29/32 | 0.02575 Å |
| ET-Flow raw | 6/32 | 32/32 | 0.02349 Å |
| + hard projection | 30/32 | 27/32 | 0.11777 Å |
| + F0.2 | **32/32** | **32/32** | **0.01770 Å** |

核心结论：raw ET-Flow 几何合理但不响应 Target_PG；hard projection 将 compatible 从 18.75%
提升到 93.75%，但制造碰撞、恶化键长；F0.2（在 orbit 代表元空间中优化 UFF + 短程排斥）才使
对称性、无碰撞和局部几何三者同时恢复。

**泛化证据**：Core-OOD 面板 32/32 compatible（与训练面板零重叠）；外部 C3k2/C3k3 共 98 个
二维图 98/98 生成成功且 C3-compatible（94 PASS + 4 WARNING）；32 条 F0.2 坐标经无约束
GFN2-xTB 松弛后 31/32 保持 compatible，唯一失败为 D6h→D3h 的真实低能降对称个例。

**能力边界（必须如实声明）**：raw ET-Flow 没有学会 Target_PG 条件响应；当前模型不能从
Target_PG 直接生成 novel SMILES/graph；same-graph swapped-PG 实验中 C2↔C3 响应仅 5/8
通过（C2↔D6h、C3↔D6h 为 8/8），说明 compatible rate 不能单独证明 target-specific
controllability——部分输出坍缩到同时包含 C2 和 C3 的共同超群。

## 七、后续研究方案：PG-OrbitFlow

### 7.1 总体设计

下一代主模型暂命名 **PG-OrbitFlow**：Point-Group-conditioned Orbit-Representative Flow
Matching for 3D Molecules。模型分为两个可独立验收的阶段：

```text
阶段 I（硕士主线）
known graph + Target_PG + recovered action
        → orbit-representative coordinate flow
        → raw PG-compatible 3D（不依赖生成后 hard projection）

阶段 II（扩展线）
Target_PG + size/property condition
        → quotient graph + orbit/action
        → 阶段 I coordinate flow
        → novel PG-compatible molecule
```

### 7.2 对称参数化：orbit representative space

每个训练样本表示为 $\mathcal D_i=(G_i, P_i, \{R_g,p_g\}_{g\in P_i}, O_i, X_i)$。把每个 orbit
的一个代表坐标记为 $q\in\mathbb R^{M\times 3}$，使用固定展开算子：

$$X = A(P,p,O)\,q$$

任意 $q$ 都对应 $X\in\mathcal M_P=\{X: XR_g^T=X[p_g],\forall g\in P\}$。当前数据的平均
coordinate DOF ratio 约为 0.47，orbit 参数化可使坐标自由度约减半。这带来四个好处：

1. 对称性不是概率事件，而是参数化本身；
2. 自由度从 3N 降为约 3×orbit_count；
3. 训练和采样全过程保持目标群作用；
4. 评测可把"对称失败"和"几何失败"分离。

### 7.3 结构化点群编码器（四级）

**一级——抽象群特征**：群阶、规范生成元及其阶、生成元关系（如 $r^3=e$）、共轭类、子群格
（显式描述 $C_3\le D_3\le D_{3h}$）。操作 token 在 Cayley graph 上做 message passing，使
encoder 对操作枚举顺序不敏感、对群结构敏感。

**二级——操作特征**：每个 $g$ 编码 $R_g$ 矩阵、行列式、迹、旋转角（$\mathrm{tr}(R_g)=1+2\cos\theta_g$）、
proper/improper/reflection/inversion 类型。

**三级——表示论特征**：特征标表、irrep 维数、平凡/非平凡 irrep mask。群对全原子坐标的联合
表示为 $\rho_X(g)=P_g\otimes R_g$；任意 irrep $\lambda$ 的投影算子为：

$$\Pi_\lambda=\frac{d_\lambda}{|P|}\sum_{g\in P}\chi_\lambda(g)^*\,\rho_X(g)$$

最终对称坐标属于 trivial irrep；网络内部保留非平凡 irrep 通道用于表达方向信息和修复向量。

**四级——分子作用特征**：置换循环类型、固定原子数、orbit size/stabilizer、atom-to-orbit
membership。对 C₃，encoder 会显式看到 $|C_3|=3$、旋转角 0°/120°/240°、原子置换三循环——
C₃ 不再只是一个类别标签。

### 7.4 对称先验与轨道空间流匹配

采样时在 orbit space 中使用 harmonic prior：

$$q_0\sim p_{\text{harmonic}}(q \mid G, P, O),\qquad X_0=Aq_0$$

从 $t=0$ 起所有状态就满足目标群。训练路径：

$$q_t=(1-t)q_0+t q_1+\sigma\sqrt{t(1-t)}\,\epsilon$$

模型预测 orbit vector field $v_\theta(q_t,t,G,P,A)$，损失按 orbit multiplicity 加权：

$$\mathcal L_{\text{orbit-flow}}=\frac1N\sum_o |O_o|\,\|v_{\theta,o}-u_{t,o}\|_2^2$$

采样时每一步只更新 $q_t$ 再展开 $X_t=Aq_t$，因此 **raw output 本身满足目标 action**。若复用
full-atom backbone，可在网络内部做 Reynolds pooling $v_X=\Pi_P F_\theta(X_t,t,G,P)$——这是
模型内部每一步的切空间约束，与生成后 post-hoc hard projection 有本质区别。

### 7.5 复合训练目标

$$\mathcal L=\mathcal L_{\text{orbit-flow}}+\lambda_b\mathcal L_{\text{bond}}+\lambda_d\mathcal L_{\text{pair}}+\lambda_c\mathcal L_{\text{collision}}+\lambda_{pg}\mathcal L_{\text{condition}}+\lambda_e\mathcal L_{\text{energy}}$$

其中：bond loss 监督键长；collision loss 使用元素对 vdW/covalent radii 而非统一 0.8 Å；
**swapped-PG contrastive loss** 对同一高对称图构造正确条件 $P$ 和可行但不同的条件 $P'$：

$$\mathcal L_{\text{condition}}=\max(0,\,m+d(X_P,\mathcal M_P)-d(X_P,\mathcal M_{P'}))$$

用于减少 C₂/C₃ 请求坍缩到共同超群。operation error 因参数化而接近机器精度，作为 assertion/
Gate 而非大权重 loss。

### 7.6 如何摆脱 F0.2 依赖

模型同时报告两个输出：raw model output（判断模型是否真正学会化学几何与 PG 条件）和 optional
physical refinement（低能交付构象）。主 Gate 必须在 F0.2 前执行。逐步降低后处理依赖的手段：
元素对 collision loss、力/能量 auxiliary supervision、蒸馏 F0.2 displacement 为 orbit-space
residual flow、最终使用 equivariant neural potential 做 differentiable energy guidance。

### 7.7 阶段 II：quotient graph 条件生成

直接生成完整 graph 再筛选 point-group automorphism 成功率极低。合理方法是生成 quotient
graph——每个节点代表一个原子轨道。给定 Target_PG，模型依次生成：orbit 数量与 size/stabilizer
类型 → 轨道代表元的元素/电荷/radical → 代表键与 bond type → 群作用 edge closure → 显式 H
补全。完整图由 $G=\mathrm{Expand}(Q,P,A)$ 展开，图自同构在结构上成立。硕士课题先实现
C2/C3 的 motif/quotient autoregressive baseline，再考虑通用离散扩散。最终模型因子分解为：

$$p(G,X,A\mid P,c)=p(Q,A\mid P,c)\,p(G\mid Q,A,P)\,p(X\mid G,A,P)$$

## 八、实验方案与评估体系

### 8.1 数据策略

| 数据层 | 内容 | 用途 |
|---|---|---|
| A：GEOM-Drugs / QMugs / SPICE | 45万分子/3,700万构象等 | 通用构象预训练（按 graph split，禁止同 SMILES 跨 split） |
| B：COF symmetry v2 | 2,532 条严格标注 | operation/orbit 监督 + 领域微调 |
| C：扩充对称数据 | Pilot ≥5,000 条（C2/C3 1:1）；Full ≥20,000 条（S4/D6h 各 ≥2,000）；每图 3-10 构象 | 平衡训练与稀有类支持 |

### 8.2 训练阶段

- **P0 数据与表示 Gate**：operation closure、permutation composition、compress→expand 误差
  ≤1e-5 Å、Si/Sn strict forward、split/leakage 审计；
- **P1 通用预训练**：GEOM/QMugs 上训练 graph→3D backbone（不含 Target_PG）；
- **P2 C2/C3 orbit flow**：冻结/小学习率解冻 graph encoder，新增群编码器与 orbit flow；
- **P3 S4/D6h 扩展**：improper operation、class-balanced fine-tuning，D6h 保持 low-support；
- **P4 quotient graph generator**：先 C2/C3 autoregressive baseline；
- **P5 联合微调与性质条件**：连接位点数、尺寸、平面性等。

### 8.3 分级 Gate

| Gate | 内容 | 门槛 |
|---|---|---|
| 0 数学/工程 | 等变性、operation error、seed 确定性 | ≤1e-5 Å |
| 1 tier-1 overfit | 单分子多 seed 过拟合 | raw 合理键长无碰撞，不调用 projection |
| 2 tier-32 transfer | 固定 32 面板 | raw compatible + collision-free + bond MAE 同时通过 |
| 3 dataset-level | IID/Core-OOD/external/xTB/controllability | 每 PG 单独报告 |

### 8.4 必做消融

PG one-hot vs 结构化操作编码器；operation set vs Cayley-graph 编码器；无/有共轭类+特征标；
trivial-only vs trivial+non-trivial irrep 通道；无/有 cycle-type+orbit-stabilizer 特征；
soft symmetry loss vs orbit 参数化；random prior vs orbit harmonic prior；无/有 collision
loss；无/有 swapped-PG contrastive loss；frozen vs fine-tuned backbone；raw vs optional
F0.2；one conformer vs multi-conformer。

### 8.5 评估指标

**化学图**：RDKit validity、connected fraction、valence/charge validity、action recovery
rate、de novo 阶段 uniqueness/novelty/scaffold novelty；
**三维几何**：bond-length MAE、键角/扭转分布、最小非键距离、conformer precision/coverage、
UFF/xTB 能量与无约束松弛 RMSD；
**对称性**：raw operation RMS、actual-PG exact/compatible、各 PG 分布与超群坍缩、
swapped-PG structural response、物理松弛后 symmetry retention；
**泛化**：canonical SMILES/Core/scaffold 隔离、test-to-train 最大 Morgan/Tanimoto、
external Cn、Sn-containing strict generation、大分子分层。

## 九、主要风险与应对

| 风险 | 应对 |
|---|---|
| 对称数据太少 | 通用构象预训练、C2/C3 起步、balanced sampler、参数高效微调 |
| graph 没有 requested PG action | known-graph 阶段严格拒绝；de novo 阶段从 quotient graph 生成 |
| raw 对称但几何不稳定 | orbit-space collision/bond loss、force distillation、F0.2 仅作安全后端 |
| 不同 PG 条件坍缩到共同超群 | swapped-PG 对比对、contrastive loss、报告 exact/actual 分布 |
| 高对称点群 analyzer 误判 | operation/permutation closure 与独立 analyzer 双证据 |
| 训练成本过高 | 先冻结 backbone 训练 orbit adapter；1→4→32 Gate 通过后才全量训练 |

## 附：答辩常见问题预答

**Q1：ET-Flow 已经能生成，为什么还需要新模型？**
ET-Flow raw 只做 graph-conditioned conformer generation，不读取 Target_PG；当前 100%
compatible 依赖生成后的 graph action/projection/F0.2。后续模型要让 raw output 自身响应
目标点群。

**Q2：hard projection 既然严格，为什么还要学习？**
projection 不理解化学能量，消融中使 collision-free 从 32/32 降到 27/32，bond MAE 从
0.02349 Å 恶化到 0.11777 Å。学习模型的任务是在对称子空间内直接生成合理几何。

**Q3：2,532 条数据够吗？**
不够从头训练高容量 de novo 模型。方案是大规模通用构象预训练 + COF 对称数据微调，并扩充
多构象和平衡点群数据。quotient graph 生成放在第二阶段。

**Q4：compatible 为什么不要求 exact？**
实际结构可能具有目标群的超群（如 requested C3、actual D3h），它仍严格满足所有 C3 操作。
但为防止超群掩盖条件坍缩，还要同时报告 exact、actual distribution 和 swapped-PG response。

**Q5：生成结构是否真实稳定？**
UFF 只是快速筛选。当前 32 条 xTB pilot 中 31 条保持 compatible，1 条 D6h 降为 D3h。后续将
增加 xTB/DFT gold subset 和无约束松弛后的对称保持率。
