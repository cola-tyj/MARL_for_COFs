# 4. 文献综述与技术路线比较

## 4.1 研究领域的四类任务

### 任务 A：de novo 3D molecule generation

从噪声联合生成原子类型和坐标，代表方法为 EDM、GeoLDM、UAE-3D。优点是可产生 novel molecule；
困难是离散化学与连续坐标耦合，且一般不保证指定分子点群。

### 任务 B：joint graph + 3D generation

MiDi、MUDiff 等同时生成 atom、bond 和 coordinates。它们避免从距离后推断键，但输出空间巨大，
对只有 2,532 条的数据从头训练风险很高。

### 任务 C：known graph → conformer generation

ET-Flow、Torsional Diffusion 等在给定化学图后生成三维构象。化学合法性较容易保证，适合作为
本课题第一阶段 backbone，但必须额外解决点群条件。

### 任务 D：symmetry-aware generation

晶体领域的 SymmCD、WyckoffDiff 把 asymmetric unit/Wyckoff orbit 与群操作作为生成表示，证明
“只生成代表元，再通过群作用展开”是一条有效路线。它们处理空间群而非孤立分子点群，但思想与
本项目的 orbit representation 高度一致。

## 4.2 代表模型及启示

| 方法 | 生成对象 | 主要特点 | 对本课题的启示 |
|---|---|---|---|
| EDM | atom type + 3D | E(3)-equivariant diffusion | 等变是必要条件，但不是指定 PG 保证 |
| GeoLDM | geometric latent | invariant/equivariant latent diffusion | 可用于大规模预训练和条件控制 |
| MiDi | graph + coordinates | discrete graph + Gaussian coordinate diffusion | joint generation 的直接基线，但训练成本高 |
| MUDiff | 完整分子多模态 | 离散/连续统一扩散 | 可比较全原子联合生成策略 |
| UAE-3D | unified latent | VAE 重构后在统一 latent 中扩散 | 先验收重构，再验收生成；本项目 tier-4 重构未通过 |
| Torsional Diffusion | known graph conformers | 在扭转角环面上扩散 | 降低自由度，但指定点群下 torsion 并非独立变量 |
| ET-Flow | known graph conformers | harmonic prior + equivariant flow matching | 当前最可靠的 learned initial-conformer prior |
| Symphony | autoregressive 3D | 高阶球谐 E(3) 特征 | 高角动量特征可增强方向表达，但不等于 PG 条件 |
| SymmCD | asymmetric unit + symmetry | 代表元与群操作联合生成 | 最接近“orbit representative + action”设计 |
| WyckoffDiff | symmetry protostructure | 在对称适配的离散表示上生成 | 支持先生成对称拓扑，再展开完整结构 |
| group-optimized diffusion | 3D molecular editing | 对群轨道优化 score labels | 可减轻排列简并并设计 operation-aligned loss |

## 4.3 为什么不建议继续只加 PG embedding

已有 learned adapter 实验说明：

- endpoint symmetry loss 可以下降；
- raw ODE 的 C3 长尾、碰撞和泛化仍失败；
- 单个分子级 scalar gate 难以表达每个 operation 和每个 orbit 的误差；
- one-hot condition 容易被强大的 graph/conformer prior 忽略。

根本原因是网络仍在完整 `N×3` 坐标空间中自由生成，然后用一个软损失鼓励其靠近低维的对称
流形。数据量有限时，模型更容易学到平均几何，而不是精确的有限群约束。

## 4.4 为什么 symmetry-by-construction 更合适

设目标群不变坐标子空间为：

```math
\mathcal M_P=\{X:XR_g^T=X[p_g],\forall g\in P\}.
```

软约束方法在整个空间训练：

```math
\mathcal L=\mathcal L_{gen}+\lambda\,d(X,\mathcal M_P).
```

symmetry-by-construction 则直接参数化：

```math
X=A_Pq,
```

使任意 `q` 都对应 `X∈M_P`。这带来：

1. 对称性不是概率事件；
2. 自由度从 `3N` 降为约 `3×orbit_count`；
3. 训练和采样全过程均保持目标群作用；
4. 评测可把“对称失败”和“几何失败”分离；
5. 与 SymmCD/WyckoffDiff 的 asymmetric-unit 思想一致。

## 4.5 与晶体对称生成的区别

晶体空间群包含平移和 Wyckoff position；孤立分子点群只包含保持一个固定点不动的有限 O(3)
操作。分子还需要处理：

- 化学图自同构与原子置换；
- 显式 H 和共振键语义；
- 柔性构象与同一图多个低能极小值；
- 点群超群/子群 compatibility；
- 成键规则和分子连通性。

因此不能直接把晶体模型搬过来，但可以迁移“quotient/asymmetric unit + group action + expansion”
的表示思想。

## 4.6 建议的 backbone 策略

### 不建议

- 在 2,532 条数据上从零训练高容量 MiDi/UAE-3D；
- 继续对失败 adapter 无界延长训练；
- 只用最终 `PG-compatible` 作为模型选择指标；
- 把 hard projection 后的成功率当作 raw model quality。

### 建议

1. 使用 ET-Flow 或同类 graph-conditioned coordinate flow 学习通用构象先验；
2. 把状态改为 orbit representative coordinates，而不是在 endpoint 做一次投影；
3. 在 GEOM-Drugs/QMugs 等数据上预训练 graph encoder/geometry layers；
4. 在当前 v2 symmetry_data 上训练 PG/action-conditioned orbit flow；
5. 新 graph 生成作为第二模块，用 quotient graph discrete diffusion 或 autoregressive grammar。

## 4.7 文献空白与本项目定位

现有分子模型多解决 E(3) 等变、属性条件或构象生成；晶体模型已有显式空间群表示，但针对孤立
有机分子的“指定 Schoenflies 点群 + 化学图自同构 + orbit coordinate generation”仍缺少成熟
通用方案。本项目已经具备：

- 严格的 operations/permutations/orbits 数据；
- graph-only action recovery；
- hard-symmetry 和物理修复基线；
- actual/exact/compatible evaluator；
- 已定位的 C3、碰撞、条件坍缩和物理降对称失败模式。

因此后续工作不是从零开始，而是把已经验证有效的约束从“生成后处理”提升为“生成模型内部
表示”。
