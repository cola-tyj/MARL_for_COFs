# 6. 实验方案与风险控制

## 6.1 数据策略

### 数据层 A：通用构象预训练

优先考虑 GEOM-Drugs：公开数据包含约 45 万个分子和 3,700 万个构象，适合学习 graph→3D
构象先验。也可使用 QMugs 的约 66.5 万分子/约 200 万构象，或 SPICE 的量子化学构象/力数据
作为能量与几何辅助训练。

下载和预处理应单独执行，不在本资料整理任务中自动启动。所有外部数据必须：

- 记录版本、URL、license 和 SHA-256；
- 按 graph split，禁止同一 SMILES 的不同构象跨 split；
- 严格过滤元素/vocab，不做未知元素 fallback；
- 保留多构象及能量/权重，而不是强制一图一构象。

### 数据层 B：当前 COF symmetry v2

用途：operation/permutation/orbit supervision 和 domain fine-tuning。训练使用 IID-train；模型选择
只用 IID-validation；IID-test/Core-OOD 在协议冻结后使用。

### 数据层 C：扩充对称数据

建议的工程目标而非理论阈值：

1. Pilot：至少 5,000 条、以 C2/C3 为主且尽量 1:1 平衡；
2. Full：至少 20,000 条，S4/D6h 各争取 ≥2,000 条；
3. 每个 graph 保存 3–10 个低能、点群兼容构象；
4. 建立一部分 xTB 优化和小规模 DFT gold subset；
5. 外部 Cn 98 图作为固定 external validation，不混入训练。

这些数字是训练工程目标，需要依据数据获取成本和 learning curve 调整，不能表述成已验证的最低
样本量。

## 6.2 训练阶段

### P0：数据与表示 Gate

- operation closure、permutation composition、orbit transitivity 全部通过；
- `compress → expand` 最大误差 ≤ 1e-5 Å；
- Si/Sn、charge、radical strict forward；
- 所有 split 和 graph leakage 审计通过。

### P1：通用 graph→3D 预训练

- 在 GEOM/QMugs 上训练或复用 ET-Flow 类 coordinate backbone；
- 先不加入 Target_PG；
- 验证 conformer precision/coverage、bond geometry 和 collision；
- checkpoint 只提供 geometry prior，不宣称对称生成。

### P2：C2/C3 orbit flow

- 冻结或小学习率解冻 graph encoder；
- 新增 operation/group encoder 和 orbit flow layers；
- C2/C3 balanced sampling；
- 加入 collision、bond 和 swapped-PG contrastive objectives；
- 训练输出从第一步到最后一步都位于目标对称子空间。

### P3：S4/D6h 扩展

- 先完成 action candidates、stabilizer 和 improper operation 测试；
- 使用 class-balanced fine-tuning；
- D6h 继续作为 low-support，除非扩充数据达到预设规模；
- 针对近球形 S4/Td/Oh 单独设计 analyzer 和 inertia audit。

### P4：quotient graph generator

- 先 C2/C3 motif/autoregressive baseline；
- 再比较 discrete diffusion；
- 只将通过 graph expansion、RDKit sanitize 和 automorphism audit 的图送入 coordinate model。

### P5：联合微调与性质条件

在图和坐标两个模块分别通过后，再加入：连接位点数量、分子尺寸、孔径代理、平面性或电子性质
条件。避免一开始同时优化所有目标。

## 6.3 分级 Gate

### Gate 0：数学/工程

- finite forward/backward；
- E(3) 等变与节点排列等变；
- operation error ≤ 1e-5 Å；
- deterministic seed、checkpoint exact resume；
- source graph fingerprint 不改变。

### Gate 1：tier-1 overfit

- 一个 C2 和一个 C3 分子各多 seed；
- raw coordinates 可过拟合到合理键长和无碰撞；
- 不调用 hard projection；
- 同图 swapped-PG 输出有可测差异。

### Gate 2：tier-4/tier-32 transfer

- 多 graph、多 PG；
- 固定 32 validation panel；
- raw PG-compatible、collision-free、bond MAE 同时通过；
- 每个 PG 单独报告，不只看 macro average。

### Gate 3：dataset-level

- IID-test；
- Core-OOD + fingerprint nearest-neighbor audit；
- external graph panel；
- same-graph multi-PG controllability；
- xTB 无约束松弛后 PG retention。

## 6.4 评估指标

### 化学图

- RDKit sanitize validity；
- connected fraction；
- valence/charge/radical validity；
- graph automorphism/action recovery rate；
- de novo 阶段的 uniqueness、novelty、scaffold novelty。

### 三维几何

- bond-length MAE；
- bond-angle/torsion 分布；
- minimum all-pair/nonbonded distance；
- conformer precision/coverage；
- UFF/xTB energy 和无约束松弛 RMSD。

### 对称性

- raw operation RMS/max atom error；
- analyzer success；
- actual-PG exact/compatible；
- 各 PG 分布与超群坍缩；
- swapped-PG structural response；
- 物理松弛后的 symmetry retention。

### 泛化

- canonical SMILES/Core/scaffold 隔离；
- test-to-train 最大 Morgan/Tanimoto；
- external Cn/其他外部分子；
- Sn-containing strict generation；
- 大分子和罕见元素分层结果。

## 6.5 必做消融

| 消融 | 目的 |
|---|---|
| PG one-hot vs structured operation encoder | 判断群结构信息是否必要 |
| operation set vs Cayley-graph/multiplication-aware encoder | 判断群乘法关系是否带来增益 |
| 无/有 conjugacy-class + character-table features | 判断表示论特征的贡献 |
| trivial-only vs trivial + non-trivial irrep channels | 判断非平凡模式是否改善几何与条件响应 |
| 无/有 cycle-type + orbit-stabilizer features | 判断分子 action 特征的贡献 |
| soft symmetry loss vs orbit parameterization | 证明 symmetry-by-construction 的贡献 |
| random Gaussian vs orbit harmonic prior | 判断对称图先验的贡献 |
| 无/有 collision loss | 判断 raw 几何改善来源 |
| 无/有 swapped-PG contrastive loss | 判断条件坍缩是否缓解 |
| frozen vs fine-tuned graph backbone | 判断小数据微调策略 |
| raw vs optional F0.2 | 严格分离模型能力与后处理贡献 |
| one conformer vs multi-conformer training | 判断构象分布学习收益 |

群特征消融必须保持 backbone、训练样本、seed 和参数预算尽量一致。除最终 actual-PG 外，还应报告：

- group-condition retrieval accuracy；
- 每个共轭类的 operation error；
- 按 orbit size/stabilizer 分层的误差；
- same-graph swapped-PG response；
- 对未在训练中出现但具有相关 subgroup/supergroup 结构的群的迁移表现。

## 6.6 主要风险与应对

### 风险 1：对称数据太少

应对：通用构象预训练、C2/C3 起步、balanced sampler、参数高效微调、数据 learning curve。

### 风险 2：graph 没有 requested PG action

应对：known-graph 阶段严格拒绝；de novo 阶段从 quotient graph 生成，避免事后筛选。

### 风险 3：raw 对称但几何不稳定

应对：orbit-space collision/bond loss、force distillation、xTB 子集；F0.2 仅作为安全后端和对照。

### 风险 4：不同 PG 条件坍缩到共同超群

应对：same-graph swapped-PG pairs、contrastive condition loss、报告 exact/actual distribution，不只
报告 compatible。

### 风险 5：高对称点群 analyzer 误判

应对：完整 operation/permutation closure 与独立 analyzer 双证据；近球形结构单独报告。

### 风险 6：训练成本过高

应对：先冻结 graph backbone、训练 orbit adapter/flow head；1→4→32 Gate；只有通过后才全量训练。
