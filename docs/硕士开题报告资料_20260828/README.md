## 一句话研究主线

```text
对称 COF 分子数据构建
        ↓
known graph + Target_PG → 3D 的可行性验证（our_ET_Flow）
        ↓
在轨道代表元空间中训练 symmetry-by-construction coordinate flow
        ↓
扩展为 Target_PG → quotient graph/action → symmetric 3D 的联合生成模型
```

## 当前已经证明和尚未证明的内容

### 已经证明

- 已构建 2,532 条具有显式 H、真实化学键、三维坐标和点群标注的 canonical 数据；
- 当前四个目标族为 C2、C3、S4、D6h，全部 2,532 条均满足严格的 target-compatible 定义；
- our_ET_Flow 可以在已知合法分子图和合法 graph action 的条件下，输出点群兼容的三维坐标；
- hard projection 单独会恶化局部几何，F0.2 对称约束 UFF 与短程排斥是必要模块；
- 完整路线在固定消融面板、Core-OOD 面板和外部 C3 图上均已有直接证据；
- 结果可在无约束 GFN2-xTB 松弛后大体保持，但 D6h 存在真实降对称个例。

### 尚未证明

- ET-Flow raw backbone 并没有学会 Target_PG 条件响应；
- 当前模型不能从 Target_PG 直接生成 novel SMILES/graph；
- `PG-compatible=100%` 不等于能区分同一高对称图上的不同子群请求；
- 当前 2,532 条、单 SMILES 单构象且类别不平衡的数据，不足以直接支撑高容量 de novo 模型从头训练；
- UFF/xTB 通过不等于实验可合成或热力学全局稳定。

## 开题报告建议使用的研究目标

开题时建议把目标分成两级：

1. **硕士阶段主目标**：实现不依赖生成后 hard projection 的
   `known graph + Target_PG + graph action → raw symmetric 3D`；
2. **扩展目标**：实现
   `Target_PG → novel valid quotient graph/action → symmetric 3D`。

这样的表述既承接当前成果，又避免把“直接生成新分子图”作为必须一次解决的单点高风险任务。
