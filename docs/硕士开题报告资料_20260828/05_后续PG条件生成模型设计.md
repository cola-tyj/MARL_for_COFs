# 5. 后续指定点群生成模型设计

## 5.1 总体设计：PG-OrbitFlow

建议将下一代主模型暂命名为 **PG-OrbitFlow**：

> Point-Group-conditioned Orbit-Representative Flow Matching for 3D Molecules

模型分为两个可独立验收的阶段：

```text
阶段 I（硕士主线）
known graph + Target_PG + recovered action
        → orbit-representative coordinate flow
        → raw PG-compatible 3D

阶段 II（扩展线）
Target_PG + size/property condition
        → quotient graph + orbit/action
        → 阶段 I coordinate flow
        → novel PG-compatible molecule
```

阶段 I 不依赖生成结束后的 hard projection；阶段 II 再解决 novel graph。

## 5.2 训练样本表示

每个样本表示为：

```math
\mathcal D_i=(G_i,P_i,\{R_g,p_g\}_{g\in P_i},O_i,X_i).
```

其中：

- `G_i`：原子、charge、radical 和 typed bonds；
- `P_i`：Target_PG；
- `R_g`：三维操作矩阵；
- `p_g`：同元素原子置换；
- `O_i`：atomic orbits；
- `X_i`：质心归零的三维坐标。

把每个 orbit 的一个代表坐标记为 `q∈R^(M×3)`，使用固定 expansion operator：

```math
X=A(P,p,O)q.
```

`M` 通常小于 `N`；当前数据的平均 coordinate DOF ratio 约为 0.47，说明 orbit 参数化可使
坐标自由度约减半。

## 5.3 条件编码器

### Graph encoder

建议使用成熟 E(3)-equivariant graph network，例如 TorchMD/Equiformer/EQGAT 类模块，输入：

- atom embedding；
- charge/radical/aromatic/hybridization；
- typed bond embedding；
- 当前展开坐标 `X_t=Aq_t`；
- 时间 `t`。

预训练阶段可复用 graph-conditioned conformer generation 数据，而不要求样本具有高点群。

### Point-group encoder

不能只使用 one-hot。建议把群特征拆成四级编码。

#### 1. Abstract-group features

- group order `|P|`；
- 一组规范生成元及其 order；
- 生成元关系，例如 `r^3=e` 或 `srs=r^{-1}`；
- conjugacy-class id 和 class size；
- subgroup-lattice embedding，显式描述 `C3≤D3≤D3h` 等包含关系；
- 小群可直接保存 canonical multiplication table，大群则保存 generator-labeled Cayley graph。

操作 token 不应被当成无结构的列表。可在 Cayley graph 上做 message passing，或在 attention 中加入
`g·h=k` 的乘法关系 bias，使 encoder 对操作枚举顺序不敏感、对群结构敏感。

#### 2. Operation features

对每个 `g` 编码：

- `R_g` 的 3×3 matrix embedding；
- `det(R_g)`、`tr(R_g)` 和 eigenvalue signature；
- proper rotation 的旋转角 `θ_g`，满足 `tr(R_g)=1+2cosθ_g`；
- identity/proper/improper/reflection/inversion 类型；
- 所属共轭类及其 character-table column。

#### 3. Representation-theoretic features

保存点群的 character table 和 irrep metadata：

- irrep label 与维数 `d_λ`；
- 每个共轭类上的 `χ_λ(g)`；
- trivial irrep 与非平凡 irrep mask；
- 必要时用 Fourier transform over finite groups 得到 group-frequency features。

群对全原子坐标的联合表示为：

```math
\rho_X(g)=P_g\otimes R_g.
```

任意 irrep `λ` 的投影算子为：

```math
\Pi_\lambda
=\frac{d_\lambda}{|P|}
\sum_{g\in P}\chi_\lambda(g)^*\rho_X(g).
```

最终对称坐标属于 trivial irrep；网络内部则可以保留非平凡 irrep 通道，用于表达方向信息、偏离
对称流形的修复向量和不同 Target_PG 之间的响应。这样不会把“最终必须不变”误解为“所有中间
特征只能是 scalar”。

#### 4. Molecular-action features

- 原子置换 `p_g` 的 cycle type；
- fixed-atom count，即 permutation character `χ_perm(g)`；
- orbit size、orbit multiplicity；
- stabilizer subgroup/order；
- atom-to-orbit membership；
- operation 对每个 orbit 的 induced permutation；
- combined representation 的 character 和 invariant-subspace dimension。

对 C3，encoder 会显式看到：`|C3|=3`、生成元 `r^3=e`、三个共轭类、空间旋转角
`0°/120°/240°`、`det=+1`、`tr(R_120)=0`，以及原子置换中的三循环/固定点。这样 C3 不再只是
一个类别标签。

### 群特征如何进入网络

建议使用三条交互通路：

1. **global group token** 调制每层 node/edge update；
2. **operation tokens** 与 atom/orbit tokens 做 cross-attention；
3. **irrep-resolved channels** 分别聚合 trivial 和 non-trivial components，再由 orbit expansion
   保证最终坐标位于 trivial invariant subspace。

对于使用球谐特征的 E(3) backbone，可将 SO(3) 的 `l` 通道限制到有限点群后，再按点群 irreps
分解。`l≥3` 可能提高角向表达能力，但它不能替代 character、conjugacy class 和 molecular
permutation action。

## 5.4 对称先验

普通 ET-Flow 使用 full-atom harmonic prior。PG-OrbitFlow 应在 orbit space 中采样：

```math
q_0\sim p_{harmonic}(q\mid G,P,O),
```

再展开为：

```math
X_0=Aq_0.
```

从 `t=0` 起所有状态就满足目标群，而不是先生成任意坐标、最后修正。prior 的协方差可由 quotient
graph Laplacian 或 orbit-level spring graph 构造，并按 orbit multiplicity 做质量归一化。

## 5.5 Orbit-space conditional flow matching

训练路径：

```math
q_t=(1-t)q_0+tq_1+\sigma\sqrt{t(1-t)}\epsilon.
```

模型预测 orbit vector field：

```math
v_\theta(q_t,t,G,P,A).
```

这里的 `P,A` 不只是 PG one-hot，而是上节定义的 abstract-group、operation、irrep 和
molecular-action features。

基本 flow loss：

```math
\mathcal L_{flow}=\frac1M\sum_{o=1}^M
\|v_{\theta,o}-u_{t,o}\|_2^2.
```

需要按 orbit multiplicity 加权，避免固定点和大轨道贡献失衡：

```math
\mathcal L_{orbit-flow}=
\frac1N\sum_o |O_o|\,\|v_{\theta,o}-u_{t,o}\|_2^2.
```

采样时每一步都只更新 `q_t`，然后通过 `A` 展开 `X_t`。因此最终 raw output 本身满足目标 action。

### 等价实现

若复用 full-atom backbone，可预测任意 atom-wise velocity `F_θ`，然后在网络内部做 Reynolds pooling：

```math
v_X=\Pi_PF_\theta(X_t,t,G,P),
```

再压缩为 orbit velocity。这里的 `Π_P` 是**模型内部每一步的切空间约束**，与生成结束后把失败
坐标改掉的 post-hoc hard projection 有本质区别。

## 5.6 复合训练目标

建议总损失：

```math
\mathcal L=
\mathcal L_{orbit-flow}
+\lambda_b\mathcal L_{bond}
+\lambda_d\mathcal L_{pair}
+\lambda_c\mathcal L_{collision}
+\lambda_{pg}\mathcal L_{condition}
+\lambda_e\mathcal L_{energy}.
```

### 键长和局部几何

```math
\mathcal L_{bond}=
\frac1{|E|}\sum_{(i,j)\in E}
(\|x_i-x_j\|-d_{ij}^{*})^2.
```

可再加入 angle cosine、ring planarity 和 chirality loss，但 canonical bond graph 不允许改变。

### 碰撞损失

对非键原子对：

```math
\mathcal L_{collision}=
\frac1{|\bar E|}\sum_{(i,j)\notin E}
[\max(0,r_{ij}^{min}-\|x_i-x_j\|)]^2.
```

`r_min` 应按元素对的 van der Waals/covalent radii 设置，训练时不能只使用统一 0.8 Å。

### Target-specific contrastive loss

对同一高对称图构造正确条件 `P` 和可行但不同的 swapped condition `P'`：

```math
\mathcal L_{condition}=
\max(0,m+d(X_P,\mathcal M_P)-d(X_P,\mathcal M_{P'})).
```

也可直接比较共享 prior/seed 下两种条件输出的结构距离，减少 C2/C3 坍缩到共同超群。

### 对称误差

由于结构按 `X=Aq` 展开，operation error 应接近机器精度。它主要作为 assertion/Gate，而不是
需要大权重优化的 loss：

```math
\max_g RMS(XR_g^T,X[p_g])\le10^{-5}\;Å.
```

## 5.7 如何摆脱 F0.2 依赖

后续模型应同时报告两个输出：

1. **raw model output**：用于判断模型是否真正学会化学几何与 PG 条件；
2. **optional physical refinement**：用于获得更低能的交付构象。

主 Gate 必须在 F0.2 前执行。可逐步降低后处理依赖：

- 训练中加入元素对 collision loss；
- 使用 UFF/xTB 产生的力或能量作为 auxiliary supervision；
- 蒸馏 F0.2 displacement：学习从 projected/raw symmetric state 到 relaxed state 的 orbit-space
  residual flow；
- 最终使用 equivariant neural potential 做 differentiable energy guidance；
- F0.2 仅保留为 baseline/safety repair，不把其成功率计入 raw generation Gate。

## 5.8 阶段 II：quotient graph 条件生成

直接生成完整 graph 后再筛选 point-group automorphism，成功率可能极低。更合理的方法是生成
quotient graph：每个节点代表一个原子轨道。

### 生成变量

给定 Target_PG，模型依次生成：

1. orbit 数量 `M`；
2. 每个 orbit 的 size/stabilizer 类型；
3. orbit representative 的元素、charge、radical；
4. orbit 之间的代表键和 bond type；
5. 群作用下的 edge closure；
6. 显式 H 或重原子图后的确定性 H 补全。

完整图由群作用展开：

```math
G=Expand(Q,P,A).
```

由于每条代表边必须同时生成整个 group orbit of edges，图自同构在结构上成立，而不是生成后猜测。

### 模型选择

quotient graph 可使用：

- discrete diffusion；
- autoregressive Transformer；
- motif/fragment grammar；
- 先生成对称 core，再生成等价 arms 的层级模型。

对于硕士课题，建议先实现 C2/C3 的 motif/quotient autoregressive baseline，再考虑通用离散扩散。

## 5.9 两阶段联合分布

最终模型可写成：

```math
p(G,X,A\mid P,c)
=p(Q,A\mid P,c)\,
p(G\mid Q,A,P)\,
p(X\mid G,A,P).
```

其中第二项为确定性或近确定性的群作用展开，真正需要学习的是 quotient graph 和 orbit coordinates。
这种因子分解比在一个模型中同时无约束生成 `N` 个 atom、`N²` 个 bond 和 `3N` 个坐标更符合
当前数据规模。

## 5.10 推荐的最小可行版本

第一版只做 C2/C3，输入 known graph/action：

```text
graph encoder
    + structured PG/operation encoder
    + conjugacy-class/character/irrep features
    + orbit-stabilizer and permutation-cycle features
    + orbit harmonic prior
    + 8–12 layer E(3) coordinate flow
    + orbit expansion at every step
    + bond/collision/contrastive objectives
```

验收目标不是一次达到 de novo molecule generation，而是：

- raw operation error ≤ 1e-5 Å；
- unseen Core 上 raw PG-compatible 明显高于 ET-Flow raw；
- collision-free、bond MAE 和 xTB stability 不显著低于 current F0.2；
- same-graph swapped-PG response 通过预冻结门槛；
- 不调用 endpoint hard projection 才能通过主 Gate。
