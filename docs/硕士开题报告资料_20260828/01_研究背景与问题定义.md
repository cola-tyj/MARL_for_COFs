# 1. 研究背景与问题定义

## 1.1 研究背景

共价有机框架（COFs）由具有特定连接数、拓扑和空间构型的有机构筑单元组装而成。构筑单元的
分子对称性会影响连接位点的等价性、网络拓扑、孔道形貌和最终材料结构。因此，若能在分子设计
阶段按指定点群生成候选构筑单元，就能把化学空间搜索从“随机生成后筛选”转化为“按结构先验
定向生成”。

三维分子生成同时包含三类约束：

1. **化学约束**：元素、价态、形式电荷和化学键必须合法；
2. **几何约束**：键长、键角、非键距离和构象能量必须合理；
3. **群论约束**：目标点群的每个空间操作必须对应一个同元素、同化学环境的原子置换。

传统 SMILES/2D 图生成主要解决第一类约束；一般 3D 等变生成模型主要处理旋转、平移和排列
等变性，却不自动保证一个具体分子具有用户请求的 C2、C3、S4 或 D6h 点群。项目的核心研究空白
正位于这两者之间。

## 1.2 必须区分的两种“对称”

### E(3)/SE(3) 等变性

若将整个输入分子旋转或平移，模型输出随之旋转或平移：

```math
f(RX+t)=Rf(X)+t.
```

这保证模型不依赖实验室坐标系，但不保证输出分子自身具有 C3 轴。

### 分子点群对称性

对于指定点群中的每个操作 `g`，需要存在空间矩阵 `R_g` 和原子置换 `p_g`，使得：

```math
XR_g^T=X[p_g].
```

这是“分子内部在某些非平凡变换下保持不变”，与模型对整体旋转等变不是同一个问题。

> 开题答辩中应明确说明：**E(3)-equivariant model 不等于 point-group-conditioned model**。

## 1.3 研究对象和任务分层

本课题把任务分成三个层次：

| 层次 | 输入 | 输出 | 当前状态 |
|---|---|---|---|
| 构象生成 | known graph | 3D conformer | 官方 ET-Flow 可提供初始构象先验 |
| 对称构象生成 | known graph + Target_PG | PG-compatible 3D | our_ET_Flow composite route 已实现 |
| 对称分子生成 | Target_PG/性质 | novel graph + PG-compatible 3D | 尚未实现，是后续扩展目标 |

主线任务可形式化为：给定分子图

```math
G=(V,E,mathbf a,mathbf b)
```

和目标有限点群 `P`，学习条件分布：

```math
p_	heta(X\mid G,P),
```

使生成坐标满足化学几何合理性和 `P <= ActualPG(X)`。

扩展任务进一步学习：

```math
p_	heta(G,X\mid P,\mathbf c),
```

其中 `c` 可以是分子大小、连接位点、元素组成或目标性质。

## 1.4 核心科学问题

### 科学问题一：如何表示“指定点群”

仅使用 C2/C3 one-hot 容易被网络忽略，也不能表达群操作与原子等价关系。需要把点群表示为：

- **抽象群特征**：群阶、生成元及其阶、生成元关系、乘法表、共轭类和子群格；
- **表示论特征**：特征标表、不可约表示维数，以及平凡/非平凡 irrep 投影；
- **空间操作特征**：操作矩阵 `{R_g}`、行列式、迹、旋转角和 proper/improper 类型；
- **原子置换特征**：`{p_g}` 的循环类型、固定原子数和 permutation character；
- **轨道特征**：`orbit_id/orbit_size`、stabilizer subgroup 和 atom-to-orbit membership。

特别地，群对全原子坐标的联合表示可写成：

```math
\rho_X(g)=P_g\otimes R_g,
```

其中 `P_g` 是原子置换表示。Reynolds projector 是该表示在平凡不可约表示上的投影；其不变子空间
维数可由特征标计算：

```math
\dim\operatorname{Fix}(\rho_X)
=\frac1{|P|}\sum_{g\in P}\chi_{\rho_X}(g).
```

这使模型不仅知道“标签是 C3”，还知道 C3 的群结构、120° 旋转操作、原子三循环和真正可用的
对称坐标自由度。

### 科学问题二：如何同时保证对称性和化学几何

对称投影能精确满足群作用，却可能缩短键长或制造碰撞；自由几何优化能降低能量，却可能破坏
点群。模型必须在**对称子空间内**学习或优化，而不是在生成结束后在“对称”和“能量”之间来回
修补。

### 科学问题三：如何实现真正的条件可控性

`Target_PG` 是实际点群的子群时即可称 compatible，但同一个高对称结构可能同时兼容 C2 和 C3。
因此必须设计相同图、相同随机初态、只替换 Target_PG 的反事实实验，判断输出是否对不同条件
产生可区分响应。

### 科学问题四：有限对称数据如何训练生成模型

当前数据只有 2,532 条，且 C2 占 79.74%，D6h 只有 14 条。合理方案是：

1. 在 GEOM 等大规模通用 3D 数据上学习化学构象先验；
2. 在严格标注的对称数据上学习点群条件和轨道约束；
3. 使用 class/orbit-balanced sampling 和 Core-OOD Gate 防止记忆模板。

## 1.5 研究假设

建议在开题报告中提出以下可检验假设：

- **H1**：在每个生成时间步将状态限制在目标群不变子空间，比只添加 PG embedding 或 soft
  symmetry loss 能获得更高的 raw PG-compatible rate；
- **H2**：在 orbit representative space 中生成，能够降低坐标自由度并减少同轨道原子间的不一致；
- **H3**：大规模通用构象预训练 + 小规模对称数据微调，比直接在 2,532 条数据上从头训练更稳定；
- **H4**：quotient graph/orbit grammar 能比“先任意生成图、再筛选 automorphism”更高效地产生
  满足指定点群的 novel graph；
- **H5**：加入 swapped-PG 对比目标，可减少 C2/C3 请求坍缩到共同超群的现象。

## 1.6 预期创新点

1. 面向分子点群而非仅 E(3) 等变的操作—置换—轨道联合条件表示；
2. 在 orbit representative space 中进行 flow/diffusion，使对称性成为生成参数化的一部分；
3. 通过 quotient graph 生成实现“图结构本身按指定点群成立”；
4. 建立 raw output、post-processing、actual-PG 和物理松弛相互分离的严格评测体系；
5. 构建面向 COF 构筑单元、覆盖 Si/Sn 和多种目标点群的可复现数据与基准。
