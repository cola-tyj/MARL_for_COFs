## 一、阶段判断

数据集构建可以冻结为 **v1**，项目应进入生成模型阶段。但“开始生成模型阶段”不等于
立即启动长时间训练，第一轮工作应先完成训练数据接口、预训练模型选型、评测闭环和
小样本过拟合测试。

以下路线不再作为当前训练入口：

- `symmcd_diffusion/train_symmetry_conditioned.py`
- `symmcd_diffusion/train_joint.py`
- `symmcd_diffusion/train_2d_graph.py`
- 旧 symmetry-conditioned diffusion、Orbit-Circulant、JT-VAE 方案

这些文件仅用于复盘失败原因。可复用的资产只有底层工具、评测经验和
`symmcd_diffusion/checkpoints/qm9_best.pt` 中部分可迁移参数。

## 二、当前事实与约束

### 2.1 数据规模

| 项目 | 当前值 |
|---|---:|
| 分子数 | 2,532 |
| 原子总数 | 91,113 |
| 元素种类 | 13 |
| 单分子原子数 | 9–105，中位数 32，P95=64 |
| 单分子重原子数 | 8–77，中位数 22，P95=45 |
| Core / Arm | 98 / 75 |
| Target_PG | C2=2,019；C3=461；S4=38；D6h=14 |

Si 仅出现在 43 个分子中，Sn 仅出现在 2 个分子中。词表必须保留 Si/Sn 的独立表示，
但第一阶段不能声称模型已经学会可靠生成 Sn；应单独报告稀有元素召回率。

### 2.2 图与坐标对应关系

训练联合图+3D模型需要把 SMILES 中的键与 XYZ 原子顺序对齐。检查和修复结果：

- 2,532/2,532 的 RDKit 加氢分子与 XYZ 元素组成一致；
- 2,532/2,532 的 RDKit 原子顺序与 XYZ 完全一致；
- 原 DataFrame 索引 1327 的例外来自合并时误引用同名文件
  `output/xyz/mol_000002.xyz`；现已改回与 `hierarchical_v1` 来源和 CSV 能量一致的
  `output/hierarchical/xyz/mol_000820.xyz`，并重新计算平面指标；
- 修复后的文件由三维坐标恢复得到 81 条键、单一连通分量，规范 SMILES 和点群 C3
  均与 CSV 一致。

### 2.3 QM9 权重边界

现有 `qm9_best.pt` 为 epoch 444、best validation loss 1.462，模型配置为 5 种元素
H/C/N/O/F、最大 29 个原子。当前数据有 13 种元素且最大 105 个原子，因此输入嵌入和
原子输出头无法原样加载。

更重要的是，历史实验已确认该模型的坐标噪声预测 MSE 约为 1.0–1.3，纯噪声采样时
坐标会放大到不合理尺度。该 checkpoint 适合作为复现实验、H/C/N/O/F 参数初始化或
对照组，不适合作为新主模型的基础。

## 三、模型路线

### 2026-08-14 候选路线：UAE-3D 重构 + UDM-3D latent generation

1. [UAE-3D](https://arxiv.org/abs/2503.15567) 先把原子类型、full-pair 键和三维坐标压缩为
   统一的逐原子 latent token；这使项目能先独立回答“COF 表示能否近无损重构”。
2. UDM-3D 再用通用 DiT 学习 latent 分布。只有 UAE 重构 Gate 通过后才启动 UDM，避免把
   decoder 重构误差与 diffusion 生成误差混在一起。
3. 官方 conditional 路径使用 adaLN condition embedding 与 classifier-free guidance，
   适合后续接入 `Target_PG`，但模型没有内建 point-group 约束，不能保证 exact symmetry。
4. SemlaFlow 和 MiDi 的历史结果继续保留：前者因原生化学有效性不稳定关闭 Gate 2；后者
   因 COF deterministic transfer 只覆盖 14/32 cases、4/8 timesteps 而停止局部调参。

UAE 官方 decoder 只输出 atom/bond/coordinate，GEOM 词表也不含 Sn。首轮只在 2,242 条
严格三头兼容记录上验证，不删除 canonical 全集；charge/radical heads 与 Sn 扩展词表在
基础重构通过后单独实现和验收。

截至 2026-08-21，UAE 基础重构没有通过 tier-4，UDM 因此前置条件未满足而未启动。新的
推荐路线先固定化学 graph，再由 graph-conditioned 3D 模型生成坐标，并使用 v2 的
operation/permutation/orbit annotation 约束点群；这样不再要求 3D 模型同时重猜稀疏键图。

### 第一阶段明确不做

- 不从随机初始化直接在 2,532 个分子上训练大型 3D diffusion；
- 不直接恢复旧 symmetry-conditioned diffusion；
- 不在第一轮加入 Point Group 条件、MARL 或性质奖励；
- 不用 `dataset.py` 中的演示 Transformer 作为正式生成模型；它只预测原子 token，
  没有完整的键和坐标生成目标。

### Phase 1：先建评测，再训练

**目标**：训练脚本的每个 checkpoint 都可以用同一套指标比较。

评测至少覆盖：

| 层面 | 指标 |
|---|---|
| 数值稳定性 | NaN/Inf、坐标半径、原子碰撞率、采样失败率 |
| 化学有效性 | RDKit sanitize、价态稳定、单连通分子比例 |
| 多样性 | valid 中的 uniqueness、相对训练集 novelty、最近邻 Tanimoto |
| 3D 质量 | 键长/键角分布、非键碰撞、MMFF 松弛成功率、松弛前后位移 |
| 数据分布 | 原子数、元素、键型、环数、Core 相似性分布 |
| 项目相关 | 松弛后实际点群、非 C1/Cs/Ci 比例、planar/nonplanar 分布 |

总力场能量不能直接作为不同分子间的稳定性排名；只使用优化是否收敛、每原子统计和
松弛前后变化作为质量检查。

**Gate 1**：评测可对真实测试集、旧 QM9 模型样本和新模型样本运行，并输出同格式 JSON。

### Phase 2：候选模型兼容性试验（SemlaFlow/MiDi 已收尾）

SemlaFlow 和 MiDi 均完成了源码锁、严格 adapter、随机 forward/backward、分级 overfit 与
生成审计，但没有通过当前数据上的完整 Gate 2。最终证据和 hash 见
[models/README.md](../generative_model/models/README.md)。它们不再进入全量训练。

### Phase 2B：UAE-3D 重构兼容性

**目标**：先证明 unified latent 能近无损恢复 COF 的 atom/bond/coordinate 三个官方字段。

1. 新建隔离 `env_uae3d`，锁定官方 commit 和完整依赖版本；
2. 用 2,242 条严格三头兼容记录构建确定性 subset，不修改 canonical v2；
3. 完成 canonical→UAE→canonical round-trip、CPU/CUDA forward/backward；
4. 对 full-pair edge、mask、显式 H、105 原子上限和动态 pair-cost batch 做压力测试；
5. 做旋转、平移和原子排列一致性测试；
6. 按 1→4→32 嵌套 tier 执行 UAE reconstruction overfit；
7. Gate 通过后才训练全部严格子集，再考虑 charge/radical heads 和 Sn 扩展。

**Gate 2B**：预先冻结的 32 分子重构阈值全部通过，无字段丢失、NaN、坐标爆炸或静默
fallback；建议目标为 atom/bond 整分子 exact 100%、sanitize/connected 32/32、coordinate
RMSD ≤ `0.05 Å`，同时报告最大误差与 SE(3)/排列审计。

### Phase 2C：UDM-3D 生成兼容性

冻结已通过的 UAE encoder/decoder，先做 1/4/32 latent overfit，再进行无条件生成。必须
独立审计原子数先验，避免把测试分子的真实原子数泄漏给生成器。只有无条件生成通过统一
P1 评测后，才允许进入全量 staged training 或 PG conditioning。

### Phase 3：分阶段微调

建议顺序：

1. **Head warm-up（5–10 epochs）**  
   冻结主干，只训练新元素嵌入、原子/键输出头和原子数先验。
2. **Partial unfreeze（20–40 epochs）**  
   解冻最后若干网络块；主干学习率约为新层的 1/10。
3. **Full fine-tune（最多约 100 epochs）**  
   全量低学习率训练，按 validation generation metrics 早停，而不是只看训练 loss。
4. **三随机种子复验**  
   配置确定后再运行 3 个 seed，报告均值和标准差。

训练实现要点：

- 按总原子数/边数动态组 batch，不能固定按分子数估算显存；
- 坐标逐分子质心归零；旋转增强在线生成，不复制到不同数据划分；
- 稀有元素采用截断的 class-balanced loss 或 sampler，避免 Sn 两个样本被无限过采样；
- 每个 checkpoint 保存 vocab、数据 manifest hash、split hash、模型配置和随机种子；
- 保留 best-validity、best-3D、latest 三种 checkpoint，不用单一 total loss 决定全部模型。

### Phase 4：无条件生成验收

首轮对每个候选 checkpoint 生成至少 1,000 个样本。以下是训练前建议锁定的临时
Go/No-Go 门槛，完成首个 pretrained zero-shot baseline 后可以统一校准一次：

| 指标 | 建议最低门槛 |
|---|---:|
| 采样数值成功率 | ≥99% |
| RDKit sanitize validity | ≥80% |
| valid 中单连通比例 | ≥90% |
| 无严重原子碰撞比例 | ≥95% |
| MMFF 可松弛比例 | ≥80% |
| valid uniqueness | ≥70% |

Novelty、点群分布和稀有元素召回第一轮先报告，不作为硬门槛。模型必须同时给出
IID test 和 Core-OOD test 结果，防止只记住“核心×臂”的已有组合。

### Phase 5：再决定条件生成与 MARL

只有无条件模型通过 Gate 4 后才进入下一决策：

1. 若模型能产生多样且化学有效的分子，但对称率低，优先比较：
   - scaffold/template conditioning；
   - flow matching 的 classifier-free guidance；
   - 生成后点群筛选。
2. C2/C3 数据量可支持第一轮条件实验；S4=38、D6h=14 不足以单独证明泛化，
   应采用模板约束或补数据，不能只靠类别重采样制造高分结果。
3. 生成器输出稳定后，再设计统一 `sample()` API 接入 MARL 候选提议和奖励计算。

这一步不是恢复旧 symmetry-conditioned diffusion，而是在新基线已经成立后重新选择
条件机制。

## 五、实验矩阵

| 实验 | 用途 | 是否长训 |
|---|---|---|
| E0：旧 QM9 checkpoint 复测 | 固化失败基线和评测格式 | 否 |
| E1：GEOM 预训练模型 zero-shot | 确认官方模型与评测可复现 | 否 |
| E2：32 样本过拟合 | 检查数据、loss、反向传播和采样 | 否 |
| E3：只训练扩展层 | 判断新词表与头部迁移能力 | 短训 |
| E4：部分解冻 | 主候选 | 是 |
| E5：全量低学习率微调 | 与 E4 比较是否过拟合 | 是 |
| E6：最佳配置 3 seeds | 最终无条件基线 | 是 |

实验按 E0→E6 逐级放行。任何阶段出现坐标爆炸、训练/采样不一致或 validity 无提升，
都应停在当前 Gate 定位问题，而不是继续增加 epoch。

## 九、v2026-08-22 Coordinate Flow Matching 新计划

本节保留 2026-08-22 Coordinate Flow 的执行计划及其最终失败，并在同节记录 R4 路线切换；
上文所有旧计划、完成项和失败结论原样保留，用于追溯决策，不因新计划而删除。详细数学定义、
Gate、优缺点与停止条件见
[Coordinate Flow Matching 新计划与可行性评估](presentation/generative_model_progress_20260821/13_Coordinate_Flow_Matching计划与可行性.md)。

### 9.1 当前任务边界

第一目标是 `known immutable graph + Target_PG + known group action/orbits → 3D coordinates`，
不是 `Target_PG → 新 SMILES`。新 graph 的生成及 symmetry permutation/orbit 推导留到 orbit
coordinate baseline 通过后处理。

### 9.2 执行顺序

1. F0：实现 centered Gaussian prior、`x_t=(1-t)x0+t x1`、显式 time condition、endpoint
   prediction 和固定 ODE integrator；通过数学、E(3)、排列、finite、resume 测试。
   **已完成**：状态 `PASS_COORDINATE_FLOW_F0`，13/13 测试通过，训练/test/Core-OOD 均未触发。
2. F1：沿用 32 IID-train + 8 IID-validation C2/C3 面板，增加 Sn-only strict forward；
   不读取 test/Core-OOD。**已完成正式实验并失败。**
3. F2：训练前冻结 Fast Flow protocol；同时评估插值恢复和 Gaussian-prior 多步采样，加入
   correct-PG vs swapped-PG 对照，hard projection 单独计分。**已完成并失败**：正式状态
   `FAIL_COORDINATE_FLOW_FAST32_STOP_ENDPOINT_BRANCH`。
4. F3/F4：因 recovery 停止条件已触发，取消 2,026 条 endpoint-flow 长训与条件增强。
5. R4：orbit 硬对称表示和 O0 工程 Gate 已通过；O1 512-step denoising 已完成并失败，故取消
   learned sampler。constrained UFF F0.1 已通过；当前转入 initial-conformer/orbit-mapping
   interface，再接已冻结的力场后端。

### 9.3 可行性判断

- F0 工程实现：高。官方 Semla backbone/integrator 已在本地，环境与严格 adapter 已验证。
- Fast-32 flow：已判失败。存在训练信号，但不能从 prior 稳定采样，不再作为微调基座。
- orbit hard-symmetry + UFF 后端：高。表示严格覆盖 2,279 条并可微；UFF 对 2,532 条全覆盖，
  F0.2 修复碰撞后，ETKDG E1 已在 32 个独立 C2/C3 validation 分子上实现不依赖真实 XYZ
  的 initial conformer；E2 已扩展到 2,232/2,232 几何成功和 99.60% independent
  compatible。当前主要缺口已从 dataset-scale 覆盖收敛为新 graph orbit 推导。
- 2,026 条 graph+PG→3D：中。数据足够开展域内训练，但单构象监督、C2 主导、显式 H 和
  105 原子上限会增加优化/显存风险。
- 最终 PG→全新分子：中低。还缺 2D graph generator 和新 graph symmetry mapping。

综合结论：coordinate-flow 路线已按冻结实验收尾；orbit hard-symmetry 是当前更可行的下一
阶段，但接口通过只是必要条件，不能提前等同于完整的指定对称性分子生成。

### 9.4 防止再次拖慢的规则

- endpoint flow 已关闭，不续训、不改 integrator、不换 backbone；
- orbit baseline 必须先冻结 C2/C3 小面板、预算、输出参数化和 Gate，再运行训练；
- 对称性只能由 differentiable hard expansion 得到，不允许把 soft symmetry improvement
  代替 raw chemistry/geometry 质量；
- 小面板未过前不给出 2,026 条长训命令；test/Core-OOD 不参与模型选择；
- 不恢复单分子 `0.05 Å` Gate，也不以降低阈值救活失败模型。

此阶段不需要下载 GEOM 或新增模型。O0 已通过；当前任务是实现 trainer 并冻结 O1 protocol；
完整 flow 历史与切换依据见
[Fast-32 Flow 结果与 Orbit 接口](presentation/generative_model_progress_20260821/16_Fast32_Flow结果与Orbit硬对称接口.md)。
